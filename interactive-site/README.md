# Codex × Claude Code × Qwen Code

Interactive, exact-version comparison report for Qwen Code product and
engineering review.

The page presents:

- the frozen product cohort and evidence boundaries;
- 53 local runtime observations across Phase 2B–2E;
- three pairwise relation explorers;
- eight Qwen decisions and their classifications;
- the final three-item proposed roadmap;
- the independently deferred R2 authorization boundary.

The report intentionally does not rank products or treat evidence counts as
feature counts.
