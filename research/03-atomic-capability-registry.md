- `notes=[]`。除 Manifest 的 `record_overrides` 外不允许行级覆写上述
  默认值；新增例外必须提升 Registry revision。

## 2. Required Contract Dimensions

表格展示层使用以下受控缩写；它们分别映射到研究方法中的精确路径：

| Code      | Exact path                               |
| --------- | ---------------------------------------- |
| `ENTRY`   | `behavior_contract.entrypoints`          |
| `INPUT`   | `behavior_contract.inputs`               |
| `AVAIL`   | `behavior_contract.availability`         |
| `SIDEFX`  | `behavior_contract.side_effects`         |
| `STATE`   | `behavior_contract.state_ownership`      |
| `PERSIST` | `behavior_contract.persistence`          |
| `OUTPUT`  | `behavior_contract.outputs_and_history`  |
| `MODES`   | `behavior_contract.runtime_modes`        |
| `CONC`    | `behavior_contract.concurrency`          |
| `FAIL`    | `behavior_contract.failure_semantics`    |
| `EXT`     | `behavior_contract.extension_boundaries` |
| `SEC`     | `behavior_contract.security_boundaries`  |
| `OBS`     | `behavior_contract.observability`        |

每行的维度集合是该原子能力进行 `Supported / Partial / Not supported` 判定时至少必须
填写的行为契约字段，不代表其他字段可以省略；非必要字段仍需显式写
`not-checked / unknown / not-applicable`。

规范化 Atomic Capability Record 的 `required_contract_dimensions` 必须保存展开后的
Exact path 数组，不保存缩写。本文表格只是无损展示投影。
