# 后台与并行

[返回 Subagent 详情目录](./README.md) · [打开网页详情](https://qqqys.github.io/code-agent/capability.html?id=agent-background)

> 核对日期：2026-10-27

## 定义

Subagent 是否能与主会话并发执行、默认落在前台还是后台，以及并发上限、查看与停止入口。

## 比较边界

### 本页包含

- 前台等待与后台运行
- 默认前后台策略与覆盖开关
- 并行派发与并发上限
- 运行中 Subagent 的查看与停止入口
- 后台结果的回报方式
- 各 Surface 的差异

### 本页不包含

- 普通 Shell 后台进程
- 多会话云任务
- Swarm 的内部算法
- 结果内容与摘要格式
- 每 Agent Worktree 隔离

## 跨产品事实

1. 五家都能让 Subagent 与主会话并发，但默认落点不同：Claude Code 在 Fork 模式开启时把 Fork 与命名 Subagent 一律放到后台，Qwen Code 的顶层命名 Agent 默认后台，Kimi Code 的 `Agent` 工具 `run_in_background` 默认 `false` 因而默认前台，Codex 官方只写并行派生后统一收集结果、不区分前台与后台，Qoder CLI 由 `background` 字段决定而官方没有给出该字段的默认值。
2. 只有 Claude Code 与 Kimi Code 公布了并发上限的具体数值或形状：Claude Code 默认单会话 20 个、`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS` 可改为任意正整数且 ultracode 会话豁免；Kimi Code 的 `AgentSwarm` 至多 128 个 subagent、ramp 阶段先起 5 个再每 700 毫秒起 1 个，`[background] max_running_tasks` 与 `KIMI_CODE_AGENT_SWARM_MAX_CONCURRENCY` 不设即无上限。Codex 的 `agents.max_concurrent_threads_per_session` 与 Qoder CLI 的 `QODER_CLI_MAX_CONCURRENT_SUBAGENTS` 都没有公布默认数值，Qwen Code 官方文档没有并发 Subagent 上限。
3. 把运行中的前台工作转到后台的快捷键只有两家记录，且覆盖范围不同：Claude Code 官方 Subagents 页写 “Press **Ctrl+B** to background a running task”，Kimi Code 官方变更记录 0.19.0（2026-06-22）逐字为 “允许使用 `Ctrl+B` 将长时间运行的前台命令和子 Agent 移动到后台任务，并通过 `/tasks` 面板查看它们。”，但现行交互指南只写 “后台运行：命令执行期间按 `Ctrl+B` 可将其转为后台任务。”、没有提子 Agent；Qwen Code 的 Subagent 文档全篇没有 `Ctrl+B`。
4. 后台结果的回报方式五种各不相同：Claude Code 把权限提示送到主会话并点名请求方，Qwen Code 用完成通知且在 TUI 与 ACP 共享一条上限 20 条的队列，Kimi Code 以合成 User 消息回到 main agent，Qoder CLI 在主会话无其他工作时先显示等待态再自动回传结果，Codex 由主线程收齐全部结果后合并成一条回复。
5. 只有 Claude Code 按前后台区分工具集，官方逐字为 “Background subagents run with a smaller built-in tool set than foreground subagents, except for conversation forks and resumed foreground subagents.”；其余四家的官方页面没有按前台或后台给出不同的工具边界。
6. 默认值随 Surface 变化，不能只按 CLI 推断：Claude Code v2.1.302 把 Fork 默认开启扩到 `claude -p`、Agent SDK、桌面端与 VS Code，同版让桌面端与 VS Code 一律后台运行主会话的 Subagent、并让这四个 Surface 里 Subagent 自己派生的 Agent 默认前台，而官方 Subagents 页在核对日期仍写 “Fork mode is off in non-interactive mode with `-p` and in the Agent SDK unless you turn it on.”；Qwen Code 的内置 `claude-code` 与 `codex` 外部执行器默认前台、headless Fork 只走后台；Kimi Code 的 print 模式默认 `print_background_mode = "steer"` 且后台 Bash 与 subagent 都不设墙钟超时。
