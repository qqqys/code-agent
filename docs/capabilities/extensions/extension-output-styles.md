# 输出风格

[返回扩展系统详情目录](./README.md) · [打开网页详情](https://qqqys.github.io/code-agent/capability.html?id=extension-output-styles)

> 核对日期：2026-11-07

## 定义

向系统提示词追加预设或自定义 Markdown 指令，改变回复的角色、语气、冗长度或结构；不改变知识库、工具或权限边界。

## 比较边界

### 本页包含

- 内置风格与选择入口
- 自定义风格文件目录与 frontmatter
- 插件携带风格与强制应用
- 选择的保存位置与生效时机

### 本页不包含

- 模型或推理强度选择
- 项目指令文件（CLAUDE.md、AGENTS.md、QWEN.md）
- Agent 定义中的系统提示词
- 整体替换系统提示词的入口（`--system-prompt`、`QWEN_SYSTEM_MD`、`SYSTEM.md`、`model_instructions_file`）
- 主题与配色

## 跨产品事实

1. 完整的输出风格机制只有三家：Claude Code、Qwen Code 与 Qoder CLI 都把风格实现为叠加到内置系统提示词上的一段命名指令，都支持用户级与项目级自定义 Markdown 风格文件。Codex 与 Kimi Code 当前都没有风格预设机制。
2. 插件携带风格只有两家：Claude Code 插件可在包内放 `output-styles/`，并用 frontmatter `force-for-plugin: true` 覆盖用户的 `outputStyle`（多个启用插件同时强制时取最先加载者）；Qoder CLI 插件按 `output-styles/` 目录约定自动发现，也可在 manifest 用 camelCase 的 `outputStyles` 显式声明，插件强制风格优先于 `outputStyle` 设置。Qwen Code 扩展的 `qwen-extension.json` 组件字段只有 `mcpServers`、`channels`、`contextFileName`、`commands`、`skills`、`agents`、`workflows` 与 `settings`，核心类型 `OutputStyleSource` 虽保留 `extension` 取值，但目录加载器只读内置、用户与项目三级。
3. 会话中切换的生效时机三家不同：Qwen Code 的 `/output-style` 保存设置后调用 `refreshSystemInstruction()` 就地重建系统提示词，官方写 “the next turn already answers in the new style”；Claude Code 自 v2.1.251 起 “Claude uses the new style starting with your next message”，此前需 `/clear` 或新会话；Qoder CLI 的 `/output-style` 官方描述是 “Choose this project's output style for the next conversation. Run `/clear` or `/new` to apply it.”，而修改配置里的 `outputStyle` 还要重启 CLI。
4. 自定义风格文件的重读时机也不同：Qwen Code 每次打开选择器或给定名字时重读目录，官方写 “a new file needs no restart”；Claude Code 官方写 “In the terminal, Claude Code reads style files when it starts, so if you create or edit one during a running session, restart Claude Code to pick up the change.”
5. 内置风格名高度重合但各自独立实现：Claude Code 官方写 “four built-in styles besides its default”（Default、Proactive、Concise、Explanatory、Learning，Concise 需 v2.1.237 及以上）；Qwen Code 的 `BUILT_IN_OUTPUT_STYLES` 是 Concise、Proactive、Explanatory、Learning 加 `default`（v0.23.0 起）；Qoder CLI 官方始终只给 `concise` 一个示例取值，没有公布完整内置清单。
6. 风格都只作用于主对话：Claude Code 官方写风格适用于主对话与 fork、“Other subagents run their own system prompt, so styles don't change how they respond.”；Qwen Code 官方写 “Styles apply to the main conversation only.”，arena peer 只在风格保留 coding instructions 时才继承会话风格；Qoder CLI 官方写 Output Style “does not alter Qoder's core identity or security constraints”。
7. 项目级风格与项目级配置都以工作区信任为前提：Qwen Code 只在 `config.isTrustedFolder()` 为真时传入 `projectRoot`，官方另写 “Trust is checked whenever the style is used, not only when the file is read”；Qoder CLI 官方写项目级与本地级设置 “only applied when the current working directory is trusted”（`security.folderTrust.enabled` 默认开启）；Codex 的项目级 `config.toml` 同样 “loaded only when you trust the project”。
