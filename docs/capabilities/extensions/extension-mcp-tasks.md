# MCP 异步任务

[返回扩展系统详情目录](./README.md) · [打开网页详情](https://qqqys.github.io/code-agent/capability.html?id=extension-mcp-tasks)

> 核对日期：2026-11-08

## 定义

MCP Server 用 tasks 扩展把一次 `tools/call` 变成服务端长任务：客户端拿到任务句柄后立即返回，之后按轮询间隔向 Server 取回状态与结果。本字段比较五家客户端是否接受这种异步应答、长时间工具调用会不会被移到后台、任务在哪里查看和停止，以及在只支持同步调用时各自用哪个超时键界定长调用。

## 比较边界

### 本页包含

- Server 以任务句柄应答 `tools/call` 时客户端的处理
- 长时间 MCP 工具调用是否自动移到后台，后台任务在何处查看与停止
- 任务的轮询、结果投递、输入请求与跨退出、恢复的跟踪范围
- 只支持同步调用时用哪个超时键界定长调用，以及连接中断后的重放条件

### 本页不包含

- MCP Server 的传输、配置作用域、认证与信任（见 MCP 客户端）
- Bash、Subagent 与 Skill 的后台执行（见后台任务）
- 工具声明的按需加载与延迟声明（见工具延迟声明与按需发现）
- 产品自己的定时任务与循环

## 跨产品事实

1. 只有 Claude Code 有一手资料记录 MCP tasks 扩展：官方 MCP 文档给出 `resultType: "task"` 应答、`tasks/get` 轮询、`tasks/update` 回答输入与 `tasks/cancel` 停止；Codex、Qwen Code、Kimi Code 与 Qoder CLI 的官方 MCP 文档在核对日期都没有 `resultType`、`taskId`、`tasks/get` 与 `pollInterval` 任何命中。
2. 另外四家都用同步超时界定长调用，但键名与默认值各不相同：Codex `tool_timeout_sec` 默认 60 秒、Qwen Code per-server `timeout` 默认 600,000 毫秒（10 分钟）、Kimi Code `toolTimeoutMs`（文档未给独立默认值，可用 `[mcp] tool_timeout_ms` 或 `KIMI_MCP_TOOL_TIMEOUT_MS` 设全局默认）、Qoder CLI `timeout`（毫秒，文档未给默认值，更新日志 CLI 1.1.3 只写 “Added timeout control for MCP tools” 而没给键名）。
3. Claude Code 把两件事分开：Server 侧的 MCP task，与「主会话任何 MCP 工具调用满两分钟自动移成后台任务」。后者自 v2.1.212 起存在、由 `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS` 控制且移成后台的普通调用不跨会话退出存活，而远程 Server 上的 MCP task 在退出后继续运行。
4. 「后台发现」与「后台执行」不是一回事：Qwen Code 的 Progressive availability 是在 UI 可交互后于后台发现 MCP Server（`discoveryTimeoutMs` 只覆盖 `connect` + `tools/list` + `prompts/list` + `resources/list` 握手），Codex 的 `mcp_optional_startup_grace_ms` 只影响启动期工具目录且官方写明 “Tool calls still need a live connection.”，两者都不改变 `tools/call` 的同步语义。
5. 连接中断后的处理只有一家有明文条件：Qwen Code 的 Connection-loss replay 要求 `trust: true`、工作区受信且工具声明 `idempotentHint: true` 或一致的只读注解才重连并重放当前调用，否则报结果可能未知；Claude Code 的 MCP task 走另一条路径——Server 断开时先从 `/mcp` 重连，否则取消请求发不出去且客户端直接忘掉该任务、无法再跟踪。
6. Claude Code 的版本坐标存在冲突：官方 MCP 页与环境变量页都写 MCP tasks 与 `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND` 需 v2.1.304 及以上，但更新日志 `## 2.1.304` 一节没有任何 MCP tasks 条目，全文检索 `MCP task`／`MCP_TASK`／`MCP_AUTO_BACKGROUND`／`tasks/get` 只在 v2.1.319 命中三条、在 v2.1.212 命中一条。
