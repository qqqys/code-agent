## 定义

把当前 CLI 会话迁移、暴露或继续到桌面端、Web、移动设备或云端运行环境。

## 跨产品事实

1. 四家有远程控制 Slash 命令：Claude `/remote-control`（别名 `/rc`）、Codex `/rc`（别名 `/remote`，rust-v0.171.0 起）、Kimi `/remote-control`（别名 `/rc`）与 Qoder `/remote-control`（带 `stop`、`status`）；Qwen 官方命令目录对 `remote` 的命中数为 0，远程入口是 `qwen serve --local-control` 一类启动旗标。
2. 本次核对把两处发布状态前移：Kimi `/remote-control` 自 0.39.0（2026-08-27）随 Release 发布、0.42.0（2026-09-09）起常驻开启且 `KIMI_CODE_EXPERIMENTAL_REMOTE_CONTROL` 已移除，此前记录的「合入 main 尚未发布、需实验开关」作废；Codex `/rc` 自 rust-v0.171.0（2026-11-20）发布，此前本字段只记了 `/app`。
3. 开关的作用范围不同：Codex `/rc` 配置的是整个本地后台服务（菜单副标题逐字为 “Applies to local sessions; cloud sessions are unaffected.”），偏好写进守护进程的 `app-server-daemon/settings.json`；Claude `/remote-control` 只作用当前会话，是否每个会话自动连接另由 `/config` 或 `remoteControlAtStartup` 决定；Kimi 与 Qoder 都是把当前会话交给中继，任务执行与产物始终留在本机。
4. 配对方式不同：Codex 在 `/rc` 菜单里选 “Add device” 取一串手动配对码，Claude 再次运行 `/remote-control` 打开状态面板给出会话 URL 与二维码，Kimi 启动即打印设备链接、终端二维码并另存 PNG，Qoder 成功后打印二维码与 URL 并由同账号的手机 App 扫码接入。
5. 云端方向相反的两条命令：只有 Claude `/teleport`（别名 `/tp`）把云会话拉进当前终端；Qoder 的 `qoder --remote` 与 `/remote-env` 是把任务送到 Qoder 托管的云 VM，属另一个方向。
6. 文档同步程度不同：Claude 与 Qoder 的官方命令表都列出了远程控制命令，Codex 的官方 Slash 命令表在核对日期仍只有 `/app`（`/rc` 只见于 rust-v0.171.0 发布说明与 TUI 源码），Kimi 的官方 Slash 命令参考仍只有 `/web`（`/remote-control` 只见于 Web 指南与源码注册表）。
