# 会话分支

[返回会话与上下文详情目录](./README.md) · [打开网页详情](https://qqqys.github.io/code-agent/capability.html?id=session-branch)

> 核对日期：2026-11-11

## 定义

复制当前会话截至某一时点的上下文，生成独立会话 ID，使新旧对话可以分别继续。

## 比较边界

### 本页包含

- 复制历史到新会话
- 新旧会话独立保存
- 分支时继承的状态边界

### 本页不包含

- Git 分支或 Worktree
- 后台 Subagent 委派
- 在同一会话中回退到检查点

## 跨产品事实

1. 五家都有直接的会话分支入口：Claude Code 用 `/branch` 加 `--fork-session`，Codex 用 `/fork`、`codex fork` 与 `codex exec fork`，Qwen Code 用 `/branch`，Kimi Code 用 `/fork`，Qoder CLI 用 `/branch` 加 `--fork-session`。此前记录的「Qoder CLI 只在 SDK 公开同类选项、TUI 命令表未列出 `/fork` 或 `/branch`」已作废：官方 Slash 命令参考的 “Sessions and Conversations” 分组列出 `/branch`（“Branch a new session from the current one.”），Sessions 页有 `## Forking Sessions` 一节，CLI 参数页有 `--fork-session` 行。
2. 命令行侧的分支入口有四家：Claude Code 用 `--continue`/`--resume` 配合 `--fork-session`，Codex 用 `codex exec fork <SESSION_ID> [PROMPT]` 并有独立的顶层 `codex fork`（默认打开会话选择器，`--last`/`--last --all` 选最近会话），Qoder CLI 用 `qoder -r <session-id> --fork-session`；Qwen Code 与 Kimi Code 的 CLI 没有等价的分支旗标，历史时点分支分别走 Daemon/SDK 与 klient/SDK/服务 API。
3. 历史时点分支有四种互不相同的锚点：Qwen Code 用 `atRecordId` 并要求目标响应有持久 `branch_checkpoint` 记录，Kimi Code 用 `turnIndex`（服务 API 的 `turn_index`，取值为持久化 engine `turnId`、允许编号空洞且该回合必须已完成），Qoder CLI 的 SDK `forkSession()` 用 `upToMessageId`，Codex 在交互式提供「空输入框连按两次 Escape 编辑上一条用户消息并从该点 fork」。Claude Code 的 `/branch` 只复制到运行命令的时点，没有历史锚点参数。
4. 回合运行中能否分支分三种口径：Claude Code 的在途后台 Subagent 与后台 Bash 继续运行、输出进入新分支；Kimi Code 自 2.5.0 起源会话继续运行，fork 只保留该回合之前最近一个已完成边界，并把当前回合的用户 prompt 存成一个仅含 prompt 的 `cancelled` 回合；Qwen Code 在回合进行中返回 `session_busy`。Codex 与 Qoder CLI 的官方资料没有说明运行中分支的行为，记为未确认。
5. `/fork` 这个名字在四家指四种不同能力：Kimi Code 与 Codex 的 `/fork` 是会话分支，Qwen Code 的 `/fork <directive>` 是继承完整对话的后台 Agent（会话分支入口是 `/branch`），Claude Code 的 `/fork` 复制到独立后台会话而 `/branch` 才是切换式分支；Codex 另有 `/side`（别名 `/btw`）是临时旁路聊天，Kimi Code 的 `:btw` 是只读工具旁路对话，两者都不计作持久会话分支。
6. 会话分支复制的是对话状态，不代表复制所有进程内授权、Goal、定时任务或工作区状态：Claude Code 的 “Allow for this session” 授权只在同进程 `/branch` 继承、`--fork-session` 新进程需重新批准，且 `--fork-session` 会阻止恢复 plan 模式；Kimi Code 不复制已保存的 `/goal`，2.2.0 起源会话的 cron 任务不再在派生会话触发。

| 字段 | 记录 |

| 矩阵结论 | `/branch` · 条件：Web Shell 可从任意已完成 Assistant 响应分支（v0.21.13 起） |
| 入口与切换 | `/branch` 从当前对话派生新会话。条件：v0.21.13 起，Web Shell 中任意已完成 Assistant 响应显示 Branch 动作，点击后从该响应分支；Daemon 提供 `POST /session/:id/branch`（可选 `name`、`atRecordId`），TypeScript SDK `DaemonClient.branchSession()` 接受 `atRecordId` 做历史分支。 |
