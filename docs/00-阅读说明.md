## 单元格怎么读

- 写出 `/model`、`isolation: worktree` 等具体值，表示一手材料已确认。
- 写“条件项”时，会同时标注平台、模式或配置条件。
- 写“未确认”表示当前没有足够的一手资料，不等于产品一定没有该能力。
- 命令矩阵中的 `—` 只表示官方 Slash 命令目录没有对应命令。
- CLI、IDE、桌面端、Web、Cloud、SDK 分开记录。

## 比较原则

1. 比较可观察行为，不把产品宣传语当作功能结论。
2. 同名能力拆到足够细。例如“支持 Subagent”会继续拆成上下文、工具、权限、后台、嵌套和工作区隔离。
3. 命令别名和主命令放在同一单元格。
4. 同一功能如果只能通过自然语言、配置或 SDK 使用，不会伪装成 Slash 命令。
5. 页面不提供产品排名、推荐结论或路线图。

## 来源优先级
