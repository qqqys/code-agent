## 模型与 Provider

| 能力 | Claude Code | Codex | Qwen Code | Kimi Code | Qoder CLI |
| --- | --- | --- | --- | --- | --- |
| 会话内切换模型 | `/model` | `/model` | `/model` | `/model` | `/model` |
| 会话内切换推理强度 | `/effort` | `/model`、`/fast` | `/effort` | 当前命令表未列出 | `/effort`、`/fast` |
| 默认模型生态 | Anthropic Claude | OpenAI | Qwen，也支持其他 Provider | Moonshot Kimi | Qoder 提供的模型目录 |
| 多 Provider | 云平台与兼容部署按官方配置 | OpenAI 及官方支持连接方式 | 支持多种 Provider 与兼容 API | `/provider` | 由产品账号和配置决定 |
| 自定义 OpenAI 兼容端点 | 依网关或云平台配置 | 依官方配置范围 | 支持 | 依 Provider 配置 | 未确认任意兼容端点 |
| 自定义 Anthropic 兼容端点 | 依官方云平台与网关配置 | 未确认 | 支持相应 Provider | 依 Provider 配置 | 未确认 |
| Agent 单独选模型 | Agent `model` | Agent `model` | Agent `model` | Agent `model_preference` | Agent `model` |
| Agent 单独设推理强度 | 依模型和 Agent 配置 | `model_reasoning_effort` | 未确认 | 主/备模型偏好为实验项 | Agent `effort` |
| 快速模式 | `/fast` | `/fast` | Agent 可选 `fast` 模型；全局依配置 | 未确认 | `/fast` |

## 认证与凭据

| 能力 | Claude Code | Codex | Qwen Code | Kimi Code | Qoder CLI |
| --- | --- | --- | --- | --- | --- |
| 浏览器账号登录 | `/login` | `codex login` 流程 | `/auth` | `/login` | `/login` |
| API Key | 支持 Anthropic API Key | 支持 OpenAI API Key | 支持各 Provider API Key | 支持 Provider 凭据 | 依产品文档 |
| 云平台凭据 | Amazon Bedrock、Google Vertex AI 等 | 依 OpenAI 官方部署方式 | Provider 配置 | 依 Provider 配置 | 未确认 |
| 环境变量 | 支持 | 支持 | 支持 | 支持 | 支持范围依文档 |
| 配置文件凭据 | 设置与云平台凭据链 | auth/config 文件与系统凭据 | settings、auth 配置 | Provider 配置 | 产品配置 |
| 退出登录命令 | `/logout` | `/logout` | `/auth logout` | `/logout` | `/logout` |
| 查看当前账号或状态 | `/status` | `/status` | `/status`、`/auth` | `/status` | `/status` |
| 企业身份与策略 | 企业账号与 Managed settings | 组织账号与 Managed config | 依 Provider 与部署 | 依产品账号 | 组织账号 |
