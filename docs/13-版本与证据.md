把不同时间、不同入口的能力混在一起。

## 证据等级

| 标签 | 含义 | 可以支持什么结论 |
| --- | --- | --- |
| 已实测 | 在记录版本和环境中真实运行 | 该版本、该系统、该入口的具体表现 |
| 官方确认 | 官方文档、官方仓库、Release、Changelog | 官方公开承诺的功能范围 |
| 源码确认 | 公开源码中能找到入口和行为 | 对开源版本的实现级确认 |
| 待验证 | 一手材料不足或不同入口冲突 | 只说明目前不能可靠下结论 |

## 公开内容边界

本仓库只发布以下材料：

- 官方文档、官方仓库、Release 与 Changelog；
- 公开源码；
- 普通用户可以重复的安装、帮助、配置和行为测试；
- 基于上述材料写成的中文比较与产品分析。

不发布非公开实现细节、第三方凭据、本机路径、内部日志或无法由读者核对的推断。资料
不足时直接写“待验证”，不会把“没找到”写成“不支持”。

## Surface 规则

同一个品牌可能同时有 CLI、IDE、Desktop、Web、Cloud、SDK。某个入口支持，不代表
其他入口自动支持。例如 Codex App 的多 Agent 工作台不能直接写成 Codex CLI 的表现；
Qwen Code Daemon 的能力也不能自动算作每个 IDE 插件都已覆盖。

每条重要结论尽量记录：

```text
产品 + 版本 + 系统 + Surface + 来源日期
```

## 更新规则

每日任务会检查一手来源。只有出现可确认且影响读者判断的变化，才修改矩阵、产品档案
或专题页，并在 [`updates/`](../updates/) 中记录。纯措辞变化和无法确认的二手消息不
进入功能结论。
