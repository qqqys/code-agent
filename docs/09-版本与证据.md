## 证据状态

| 状态 | 判断条件 |
| --- | --- |
| 官方确认 | 官方文档、官方仓库、Release 或 Changelog 直接描述该功能 |
| 源码确认 | 公开源码能定位入口、配置或行为 |
| 运行确认 | 在记录版本、系统和 Surface 中实际执行 |
| 条件项 | 只在特定系统、账号、模式、功能开关或 Surface 中成立 |
| 未确认 | 当前一手材料不足，或不同一手材料冲突 |

## Surface 规则

每条结论至少绑定到以下信息：

```text
产品 + 日期或版本 + Surface + 来源
```

CLI、IDE、桌面端、Web、Cloud 和 SDK 分开判断。某个 Surface 出现功能，不代表其他 Surface 自动具备相同命令、权限边界或会话行为。

## 更新规则

1. 先更新对应 Markdown 表格和网页数据。
2. 命令新增、删除或改名时，更新对照表和完整命令目录；不能只扫描命令实现目录，还要核对硬编码命令、bundled Skill、用户/项目/扩展 Skill、Markdown/TOML 命令、保存的 Workflow 和 MCP Prompt 加载器。
3. Subagent 行为变化时，拆分到上下文、权限、工具、后台、嵌套或 Worktree 对应行。
4. 无法从一手资料确认时保留“未确认”，不根据相似产品推断。
5. 每次影响矩阵内容的修改写入 [`updates/`](../updates/)。
