# 增加扩展系统能力独立详情页

扩展系统从一张汇总矩阵拆成 7 个可打开的能力页，覆盖 MCP、Skills、Hooks、插件、自定义命令、项目指令和 IDE 连接。

本次逐产品补充入口、配置目录、作用域、扩展构成、加载方式、适用界面、权限边界和官方来源，并同步修正以下旧结论：

- Codex 的 IDE 上下文命令是 `/ide-context`，并同步修正 Slash 命令矩阵。
- Kimi Code 的 IDE 入口是 `kimi acp`；`/editor` 只编辑当前输入。
- Qoder CLI 已公开独立插件管理和 ACP 入口。
- Qwen Code 自定义命令使用 `.qwen/commands/*.md`；保存的 Workflow 不再混入这一字段。
- Codex 项目 Skill 目录使用 `.agents/skills/`。

网页与 Markdown 使用同一份矩阵数据和详情记录。
