# Subagent 轮数与超时限制核对

核对五个产品的 Subagent 轮数、超时和并发限制字段。Kimi Code 从"未确认独立字段"更新为已确认的全局 `[subagent] timeout_ms`；Claude Code 和 Codex 补足全局并发与嵌套限制。

## 修正

- Kimi Code：`config.toml` 的 `[subagent] timeout_ms` 限制单个 Agent 或 AgentSwarm 运行时间，默认 7200000 ms（2 小时），print 模式未设置时默认 0（无限制）；环境变量 `KIMI_SUBAGENT_TIMEOUT_MS` 可覆盖；Agent 定义 frontmatter 无独立 `maxTurns` 或 `timeout` 字段。
- Claude Code：补足全局 `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`（默认 20）、`CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`（默认 200）和 `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`（默认 3）。
- Codex：矩阵结论从"并发数可配置"改为具体键名 `agents.max_concurrent_threads_per_session`；补足旧名 `agents.max_threads` 仍可用、`agents.default_subagent_model` 和 `agents.default_subagent_reasoning_effort`。
- Codex Subagent 文档 URL 从 `developers.openai.com/codex/subagents` 更新到重定向后的 `learn.chatgpt.com/docs/agent-configuration/subagents`。
