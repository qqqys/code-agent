# TUI 快捷键自定义能力字段与 Codex 双键 chord

Codex 在 2026-08-01 的官方仓库提交中为 TUI keymap 增加双键 chord 支持（如 `ctrl-x ctrl-s`），并接受两键绑定、页脚待命提示、1 秒超时取消和冲突拒绝。矩阵此前没有任何字段记录快捷键自定义能力，本次新增 `cmd-keymap`（TUI 快捷键自定义）字段，覆盖五家产品，并把 Codex 双键 chord 作为该字段的 Codex 详情记录。

## 修正

- 新增能力字段 `cmd-keymap`（Slash 命令域）：Claude Code 与 Codex 提供逐项快捷键自定义，Qwen Code、Kimi Code 与 Qoder CLI 当前官方文档未列出同类入口。
- Claude Code 详情：`/keybindings` 打开或创建 `~/.claude/keybindings.json`；绑定按 `context` 组织 `namespace:action` 动作，支持空格分隔的 chord（如 `ctrl+k ctrl+s`），`null` 解绑默认快捷键，修改自动生效；`Ctrl+C`、`Ctrl+D`、`Ctrl+M` 与 Caps Lock 保留；Vim 按键不经此文件重映射。
- Codex 详情：`/keymap` 重映射并持久化到 `config.toml`；配置键为 `tui.keymap.<context>.<action>`（context 包括 `global`、`chat`、`composer`、`editor`、`vim_normal`、`pager`、`list`、`approval` 等），空数组解绑；双键 chord 最多两键，待命中 chord 在页脚提示，`esc`、上下文切换或 1 秒超时后取消，冲突绑定被拒绝；chord 行为标注为官方仓库提交确认，官方配置文档尚未记录。
- Qwen Code、Kimi Code、Qoder CLI 详情记录边界：Qwen 仅 `/vim` 开关与 `general.vimMode`（默认 `false`）；Kimi 命令目录与 `config.toml`/`tui.toml` 未列出快捷键自定义；Qoder 仅 `/vim` 切换 Vim 编辑模式。
- 新增来源 `claude-keybindings`（官方快捷键文档）与 `codex-keymap-chords`（固定到实现提交 SHA）。
- `site/data.js` 的 `updatedAt` 更新为 2026-08-03；五家核对日期同步更新。
- 修正 `docs/capabilities/README.md` 生成器中扩展系统能力数由 7 改为 8（与实际详情文件数和 README 一致）。

## 证据版本

- Codex 官方仓库提交 `1e85ca099e4265bf89f4016772d299816e231bb3`（`Support two-stroke TUI key chords (#36511)`）：TUI keymap 配置接受 `ctrl-x ctrl-s` 双键绑定，数组仍表示同一动作的替代绑定；chord 按活动上下文路由并显示待命与配置提示，`esc`、上下文切换或 1 秒超时取消；`/keymap` 支持捕获、添加、替换和显示 chord；与已启用单键绑定、跨上下文 chord 或保留终端快捷键冲突的 chord 被拒绝。
- Codex 官方 CLI 命令文档：`/keymap` 描述为 “Remap TUI keyboard shortcuts.” 与 “Inspect and persist custom shortcut bindings in `config.toml`.”。
- Codex 官方配置参考：`tui.keymap.<context>.<action>` 类型 `string | array<string>`，空数组解绑，键名为 `ctrl-a`、`shift-enter` 等规范化字符串；未记录 chord 语法。
- Claude Code 官方快捷键文档：`~/.claude/keybindings.json` 位置、`bindings` 数组与 context/action 结构、chord 语法、保留快捷键、`null` 解绑、修改自动生效与 Vim 按键例外。
- Qwen Code 官方设置文档（`8a44b1b9f79341a0faca9814fb1b57f0f1b354a2`）：`general.vimMode`（boolean，默认 `false`）；未列出其他逐项快捷键设置。
- Kimi Code 官方配置文档（`29783e471afcf7975852e496907646458264d2e6`）：`tui.toml` 仅覆盖主题、粘贴、通知等界面偏好；命令目录无快捷键自定义命令。
- Qoder CLI 官方命令与使用文档：`/vim` 描述为 “Toggle Vim edit mode”；未列出逐项快捷键自定义。
