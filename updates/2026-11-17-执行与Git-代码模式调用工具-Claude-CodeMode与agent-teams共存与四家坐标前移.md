# 代码模式调用工具：Claude Code v2.1.326 让 Code Mode 与 agent teams 共存（teammates 只在默认 in-process 显示模式下跑 Code Mode），其余四家证据坐标前移

日期：2026-11-17
能力字段：`execution-code-mode`（执行与 Git · 代码模式调用工具）

## 本次改动

官方来源快照里 Claude Code 的最新 Release 是 v2.1.326（2026-11-16T22:11:05Z）。核对固定到该 tag 的 `CHANGELOG.md` 后确认，`## 2.1.326` 段的第一条 Added 逐字为 “Added support for turning on Code Mode while agent teams are enabled; if you already turned it on, sessions with teams on now start in Code Mode”，即 Code Mode 与 agent teams 由「互斥」变为「可共存」。

这一层此前在本仓库是反着记的。`execution-code-mode` 的 Claude 记录（2026-11-15 取证）写「Requirements 六项」并把 agent teams 列进「开着就起不来」的设置清单，故障表 `it can't be used together with agent teams yet` 一行的处理办法只有「取消 `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS`」。核对 2026-11-17 的 Code Mode 专页（`.md` 孪生体已由 15,659 字节增至 16,977 字节）后确认官方页面同步改过四处：

1. **Requirements 由六项加 Windows 变为八项**，新增的 **Agent teams** 项逐字为 “to use Code Mode with [agent teams](https://code.claude.com/docs/en/agent-teams.md) on, you need v2.1.326 or later. Teammates run in Code Mode in the default [in-process display mode](https://code.claude.com/docs/en/agent-teams.md#choose-a-display-mode), and start without it in split panes”。
2. **清单后的排除句删掉了 agent teams**，由 “such as an API key helper, agent teams, OpenTelemetry export, or `DISABLE_TELEMETRY`” 改为 “You also can't start Code Mode with some settings on, such as an API key helper, OpenTelemetry export, or `DISABLE_TELEMETRY`. For the fix for each, see Code Mode doesn't start.”。
3. **故障表 `it can't be used together with agent teams yet` 一行的处理办法改写**为 “To keep agent teams on, [update Claude Code](https://code.claude.com/docs/en/setup.md#update-claude-code) to v2.1.326 or later. To stay on your version, unset `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS`”，即取消变量降级为「留在旧版本」时的办法。
4. **`it doesn't work in background jobs` 一行补上 teammate 场景**：“Start in the foreground, without `--remote-control`. If the reason shows in a teammate's split pane, use the [in-process display mode](https://code.claude.com/docs/en/agent-teams.md#choose-a-display-mode) to run teammates in Code Mode”，把 split-pane teammate 起不来 Code Mode 明确归到「后台任务」这一类原因下。

因此共存是有条件的：**teammate 跑不跑 Code Mode 取决于 agent teams 的显示模式**。核对 Agent teams 专页（`.md` 孪生体 44,239 字节）的 “Choose a display mode” 一节，两种模式逐字为 **In-process**（“all teammates run inside your main terminal. Use the up and down arrow keys in the agent panel to select a teammate, then press Enter to view it and type to message it directly. Works in any terminal, no extra setup required.”）与 **Split panes**（“each teammate gets its own pane. You can see everyone's output at once and click into a pane to interact directly. Requires tmux, or iTerm2.”），默认值逐字为 “Teammates run in-process until you change the [`teammateMode`](https://code.claude.com/docs/en/settings-reference#teammatemode) setting.”。Settings reference 的 `teammateMode` 段（全页 `.md` 457,514 字节）给出四个取值 `"in-process"`（默认）、`"auto"`（“split panes when you're running inside tmux, or inside iTerm2 with `it2` on your `PATH` or tmux installed; in-process otherwise”）、`"tmux"` 与 `"iterm2"`，Scope 为 “Any file. Claude Code also reads a value left in `~/.claude.json` by older versions.”，并写 “Per-session overrides: `--teammate-mode` takes precedence over this key for one session”。**没有 `"split"` 这个字面值**，Agent teams 页里的 “split panes” 是显示模式的通称而不是 `teammateMode` 的取值。

两处边界按证据不足记为未确认，没有从相似产品推断：Agent teams 专页对 `code mode`／`CODE_MODE` 的命中数为 0，官方没有解释 split-pane teammate 为什么带不起 Code Mode，「因为它被当作后台任务」只能由故障表把它归到 `it doesn't work in background jobs` 一行反推；v2.1.326 另外三条与 Code Mode 有关的 Improved／Changed（“Improved permission checks in Code Mode; more sandboxed commands now ask or are refused”、“Improved the messages shown when Code Mode can't be turned on, so they say what you can do”、“Changed Code Mode's `$` shell helper to refuse some values with an error; nothing runs”）都没有给出受影响的沙箱规则、原因文案或 `$` 助手取值，具体范围同样记为未确认。

同一专页另有三处与本字段相关但不属 agent teams 的变化，一并补录：账号要求的不可用清单末尾新增 “or [Claude Models on Google Cloud (Anthropic managed)]”（此前只到 Microsoft Foundry）；故障原因表由 11 行增至 13 行，新增 `it doesn't yet work with the plugin`（处理办法逐字为 “In a session, run `/plugin` and disable each plugin that the reason names. If your organization turned one on, ask your administrator to turn it off”），API 一行的原因文本也扩为 “`it only works directly with the Anthropic API` or `it only works with the Anthropic API`”；权限段新增复合命令提醒，逐字为 “If you have a `PreToolUse` hook that allows or blocks shell commands, make it check each part of a command, as [Bash rules do](https://code.claude.com/docs/en/permissions.md#compound-commands). In Code Mode, a `git push` in a folder named `app` can reach your hook as `cd 'app' && git push`.”，即代码模式会把带 `cd` 前缀的复合命令原样交给 Hook，只匹配尾部命令名的 Hook 会漏判。NOTE 末尾另新增 “To share feedback, run `/feedback`.”。
