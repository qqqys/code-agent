# 跨会话记忆：Qwen Code v0.25.0 把 Mem0 外部记忆服务内置进主 CLI，并补录 `pinned/` 与结构化召回

Qwen Code 在 2026-10-05 发布 v0.25.0，发布说明的 Features 段列出 `feat(memory): bundle Mem0 with the main CLI (#12891)`。该 PR 的合并提交为 `abcf23a3d9b184bb850fb46bd706cd206082366a`（2026-09-30 合入 main），新增官方功能文档 `docs/users/features/mem0.md`、设置文档 `memory.mem0` 段与 `packages/cli/src/config/mem0-settings.ts`。矩阵此前记录的 Qwen 跨会话记忆只有 `QWEN.md` 与 Auto-memory，没有任何外部记忆服务连接；本次以官方文档加固定提交源码为一手来源，把这一新能力并入既有 `session-memory`（跨会话记忆）字段，而不是新增同义字段。

同一字段的 Qwen 证据版本也一并前移：矩阵此前把 Qwen 记忆文档固定在提交 `8a44b1b9f793`，该快照早于官方记忆文档记录 `pinned/` 保护目录（自 v0.22.0 起）与结构化召回（自 v0.24.7 起）的两节，因此这两项此前未进入矩阵。本次改用 v0.25.0 的记忆文档与设置文档，并保留 v0.24.7、v0.22.0 两个发行版标签用于确定首次出现版本。

其余四家同日复核：Claude Code 记忆文档补录了此前未记录的 `autoMemoryEnabled`、`autoMemoryDirectory`、`CLAUDE_CODE_DISABLE_AUTO_MEMORY=1` 与 `CLAUDE_CODE_PROJECT_DIR_NAME`；Codex 官方 Memories 页补录了 `memories.*` 六个配置键，官方 CLI Slash 命令表已列出 `/memories`；Qoder CLI 记忆页与 Kimi Code（最新提交停在 2026-09-30）没有一手资料变化。四家官方记忆文档都只描述保存在本机的记忆，没有内置的外部记忆服务连接配置。因此 Claude Code、Codex 与 Qwen Code 的核对日期更新为 2026-10-05，Qoder CLI 保持 2026-10-04、Kimi Code 保持 2026-10-03。
