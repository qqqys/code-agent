# 配置：Codex main 分支新增 `/config` 可搜索偏好面板，五家配置命令的入口、参数、保存位置与生效时机补齐

Codex 官方仓库在 2026-10-10 合入提交 [`cc7ba33601286a751477832b01de7b6f8de0dd9c`](https://github.com/openai/codex/commit/cc7ba33601286a751477832b01de7b6f8de0dd9c)（PR #52990，标题逐字为 “Add a searchable `/config` preferences panel to the TUI”），给 TUI 新增了一条 `/config` 命令：源码描述逐字为 “configure Codex preferences”，打开标题为 “Configuration” 的可搜索偏好面板。前一个提交 [`de8fab6d7adfcef8b4ce6f02f3b5c8be4092015a`](https://github.com/openai/codex/blob/de8fab6d7adfcef8b4ce6f02f3b5c8be4092015a/codex-rs/tui/src/slash_command.rs) 的 `SlashCommand` 枚举只有 `DebugConfig`、没有 `Config`，因此这是新增命令而不是既有命令改行为。

这是本仓库尚未记录的一手确认新功能。此前 `cmd-config`（配置）字段的 Codex 列只写 `/debug-config`，并把它标为「只读诊断，不是通用配置编辑器」；Codex 也因此是五家里唯一没有会话内配置面板的一家。本次只处理 `cmd-config` 一个字段，补录 Codex 的 `/config` 面板，并把其余四家的配置命令逐项核对到当前一手资料。

核对日期该提交尚未进入任何 Release：官方 Release 列表最新为 rust-v0.163.0-alpha.5（2026-10-10T00:26:59Z），早于该提交；官方 CLI Slash 命令表列出的 54 个命令里也没有 `/config`。因此 Codex 列的证据状态记为「条件项」，并写明 main 分支与尚未发布。
