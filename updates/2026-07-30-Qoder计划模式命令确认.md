# Qoder CLI `/plan` 命令确认

核对 Qoder CLI 官方权限文档，确认 `/plan` 是独立的会话内命令。

## 修正

- Qoder CLI `cmd-plan` 矩阵结论从"通过 Agent 或配置；无独立命令"更正为 `/plan`。
- `/plan` 切换 Plan 工作状态；Plan 独立于权限模式，可与任意 permission mode 共存。
- 激活后只读探索并输出方案，写入仅限计划文件。
- `general.plan.enabled: false` 可禁用；禁用后 `/plan` 不可用，`--permission-mode plan` 回退 `default`，`EnterPlanMode`/`ExitPlanMode` 工具不注册。
- Qoder CLI 命令目录增加 `/plan`。
- 证据状态从"未确认"更正为"官方确认"。
