# 增加会话与上下文能力独立详情页

## 本次更新

- 为恢复、分支、命名、压缩、上下文占用、导出、检查点和跨会话记忆增加 8 个独立详情页。
- 每页固定对照五家的入口、保存位置、具体行为、状态范围、自动行为、保留方式、适用界面、条件和官方来源。
- 主矩阵中的 8 个能力名称可直接进入 Markdown 详情；网页对应行可进入完整能力页面。
- 总计完成 66 个能力详情、330 条逐产品记录。

## 字段修正

- Qwen Code 的会话分支只记录 `/branch`；`/fork` 是继承完整对话的后台 Agent。
- Codex 会话命名移除 `/title`，上下文占用移除 `/usage`；分别使用 `/rename` 和 `/status`。
- Kimi Code 的上下文占用使用 `/usage`，并明确 `/undo` 不回滚代码。
- Qoder CLI 的 `/context-window` 是窗口设置，`/usage` 是套餐用量；会话分支和文件回退分别标为 SDK 条件能力。
- 五家的恢复、压缩、记忆和检查点记录补充了保存位置、自动行为、保留范围和不会继承的状态。
