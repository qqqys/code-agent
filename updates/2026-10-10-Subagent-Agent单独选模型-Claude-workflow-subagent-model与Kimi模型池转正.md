# Agent 单独选模型：Claude Code v2.1.296 的 `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL`，Kimi Code Subagent 模型池 0.42.0 起始终开启

Claude Code 官方 [CHANGELOG](https://github.com/anthropics/claude-code/blob/2301018b1f61073c501a8e7a4813ef48c239163b/CHANGELOG.md) 的 v2.1.296（2026-10-09 发布）有一条本仓库尚未记录的一手确认新功能，逐字为 “Added `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` to run every workflow agent on one model while other subagents keep theirs”。它和已有的 `CLAUDE_CODE_SUBAGENT_MODEL`／`CLAUDE_CODE_SUBAGENT_MODEL_FORCE` 是三个作用范围不同的变量：前两者管所有 subagent、teammate 与 workflow agent，新变量只统一 workflow agent 而其余 Subagent 保留各自模型。

核对同一字段时发现另外两处过期：Kimi Code 官方 [config-files.md](https://github.com/MoonshotAI/kimi-code/blob/c9f01f07388abc2cdca40c9c5267f58c65086710/docs/zh/configuration/config-files.md) 现在逐字写“模型池始终可用，无需任何开启动作”，而矩阵与详情仍把 Subagent 模型池记成需要 `KIMI_CODE_EXPERIMENTAL_SECONDARY_MODEL=1` 的实验性功能；Claude Code 官方 [Subagents](https://code.claude.com/docs/en/sub-agents) 页已在 Choose an effort level 小节记录每次调用的 `effort` 参数及其优先级，而详情仍写“官方只记录每次调用的 `model`、尚未记录每次调用的 `effort`，优先级未确认”。

本次只处理 `agent-model`（Agent 单独选模型）一个字段，把五家的模型字段取值、每次调用参数、完整解析顺序、派生默认模型、强制统一开关、内置 Agent 模型与跨 Provider 策略逐项核对到当前一手资料；同一批证据直接推翻的两条记录（Kimi 模型池的实验性与 `model_preference`、Claude 每次调用 `effort` 的文档状态）一并在 `agent-effort` 与 Subagent 概况里改正，Kimi `[swarm] timeout_ms` 的发布状态也在同一处改正。
