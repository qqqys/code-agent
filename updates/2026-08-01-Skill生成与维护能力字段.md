# 新增 Skill 生成与维护能力字段

Qwen Code 在 2026-08-01 的文档提交中公开了 Skill 学习（`/learn`）、Auto Skill 自动生成与 `/curator` 维护。这是一手资料确认、矩阵尚未记录的新功能。本次新增扩展系统能力字段 `extension-skill-generation`（Skill 生成与维护），并按五家官方 Skills 文档核对生成与维护边界。

## 新增

- 新增能力字段 `extension-skill-generation`（扩展系统分类），覆盖五个产品；能力字段总数由 104 增至 105，扩展系统详情由 7 个增至 8 个。
- Qwen Code 记录：`/learn <source> [focus]` 从 URL、本地路径、文本或视频生成项目 Skill，写入 `.qwen/skills/learned-skill-<name>/SKILL.md`（frontmatter `source: learned`）；Auto Skill 只管理 `.qwen/skills/auto-skill-*`（`source: auto-skill`），30 天无成功使用或编辑标记 stale、90 天整目录移到 `.qwen/archived-skills/`、不永久删除，受信任工作区每 7 天至多自动维护一次；`/curator` 提供 status、`run --dry-run`、`run`、`pin`/`unpin`、`restore`，应用维护需受信任且非 safe mode 工作区；普通会话监视个人与项目 Skill 目录并短延迟热刷新，bare mode 不监视。视频学习需 OpenAI 兼容 Provider 上的视频模型。
- Claude Code 记录：无通用 `/learn`；`/run-skill-generator` 记录构建与启动配方到 `.claude/skills/run-<name>/`，`/verify` 可写入并修正 `.claude/skills/verify/SKILL.md`；`skill-creator` 插件用于评测与描述调优；无按活跃度归档的 curator。
- Codex 记录：Record & Replay 录制工作流起草 Skill，`$skill-creator` 问答生成（默认仅指令），`$skill-installer` 安装策展 Skill；无 Auto Skill 与归档 curator，停用走 `[[skills.config]]` 的 `enabled = false`。
- Kimi Code、Qoder CLI 记录：Skill 仅手动编写 `SKILL.md`，官方文档未列出任何自动生成、`/learn` 或归档/清理未使用 Skill 的维护功能。
