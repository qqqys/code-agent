# 自定义 Slash 命令：Codex `/presets` 把可复用提示词与命令存进用户配置的十个数字槽位，五家命令模板机制逐项核对

Codex 官方仓库于 2026-10-15 由四个提交合入 `/presets`：PR #54380 “Add `/presets` for reusable prompts and slash commands”（提交 `dcd9e954598cd5e9f80570204896d779c60c1ecd`，2026-10-15T18:51:21Z）、PR #54381 “Add a keyboard shortcut menu for presets”（`111362a6a0a92d08885b1ae62d3760714907ad94`，18:51:22Z）、PR #54385 “Allow saving current permission settings as presets”（`36803b180a50e611331b75ff2b4c475c02846b53`，18:51:22Z）与 PR #54388 “Add quick dial presets for terminal title and status line layouts”（`f847a4bd3c6ca3d8474a6e0dace1ed39f7ec0067`，18:51:23Z）。`SlashCommand::Presets` 的描述逐字为 “run or save reusable prompts and slash commands”，槽位类型 `codex_config::types::QuickDial` 的注释逐字为 “One reusable prompt or slash command submitted through the TUI composer.”，持久化文件头注释逐字为 “Persist numbered prompts and slash commands in the active user configuration. Replace slots owned by the active user config. Clearing must not reveal a shadowed slot from another configuration layer.”。这是本仓库 `extension-custom-commands` 字段此前没有记录的一手确认新功能：原矩阵结论只有 “Skills；`/prompts:*` 已弃用”，原详情还专门写着 “不能把它表述成与其他四家同等的现行项目级 Command 系统”。`/presets` 给出的不是项目级 Command 目录，而是第三条路——把最多十个数字槽位写进用户配置文件，槽位内容可以是一条提示词，也可以是一条 Slash 命令行，按 `0`–`9` 直接召回。

同一字段另有四处一手资料变化尚未记录：Claude Code 官方已把自定义命令并入 Skills（Skills 页逐字为 “**Custom commands have been merged into skills.**”，命令文件改称 “the older format”，官方 Commands 页全页不再出现 `.claude/commands`），并且位置参数改为 0 基（`$0` 是第一个参数）；Qwen Code 的 TOML 命令格式已被官方标为弃用并带自动迁移提示；Qoder CLI 的自定义命令页写明用户级覆盖项目级（与 Qwen Code 的 “Project commands > User commands” 相反），而本仓库此前只固定了 Slash 命令参考页、没有固定 `https://docs.qoder.com/cli/commands`；Kimi Code 的插件斜杠命令一节自本仓库固定的 `691ec4679ea1` 起只有文字润色，但 2.2.0 Release 里那条看似相关的 “Replace user skill cards with highlighted prompts and support Ctrl-S for skill prompts.” 经复核属消息渲染与 steer 投递，不保存提示词。

本次处理 `extension-custom-commands`（扩展系统 · 自定义 Slash 命令）一个字段，补录 Codex `/presets` 的槽位模型、校验、层归属、召回路径、菜单与键位，并把其余四家在同一层的目录、命名、占位符、优先级、加载与 Headless 边界逐项核对到当前一手资料。因为 `/presets` 同时是一条新的 Codex Slash 命令，按[版本与证据](../docs/09-版本与证据.md)的更新规则第 2 条同步了 `docs/01-Slash命令矩阵.md` 的对照表与 Codex 命令目录，以及 `cmd-custom`（Slash 命令 · 自定义命令）的 Codex 一格，避免两页互相矛盾。
