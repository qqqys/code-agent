# 扩展系统：新增输出风格能力字段（Claude Code v2.1.237 内置 Concise、Qoder CLI `outputStyle`、Codex `personality`）

Claude Code v2.1.237（2026-08-20 发布，更新日志提交 `770933ea1ad2`）新增内置 "Concise" 输出风格。矩阵此前没有输出风格字段：Claude Code 的输出风格机制（`/config` Output style、`outputStyle` 设置、用户/项目/受管/插件四级自定义 Markdown、`force-for-plugin` 强制风格）只作为插件分发字段的一行组件被提及。本次新增 `extension-output-styles`（输出风格）字段并覆盖五家：Claude Code 与 Qoder CLI 都有完整的输出风格机制（内置/自定义 Markdown、插件携带、强制风格覆盖），Codex 的相近能力是 `personality` 沟通风格（无自定义风格文件），Qwen Code 与 Kimi Code 的官方配置与扩展文档均未列出输出风格。上一单元（2026-08-20 模型选择）已把 v2.1.237 Concise 输出风格标记为"无对应既有字段，留待后续单元处理"，本次即为该后续单元。

## 修正

- 新增 `extension-output-styles`（输出风格）字段，归入扩展系统分类，定义为"以预设或自定义 Markdown 修改系统提示词，改变回复的角色、语气、冗长度或结构"。
- 矩阵结论：Claude Code "`/config` Output style · `outputStyle` · `.claude/output-styles/` 自定义 · v2.1.237 新增内置 Concise"（官方确认）；Codex "条件：`personality`（`none`/`friendly`/`pragmatic`）· `/personality`；仅适用宣告 `supportsPersonality` 的模型"（条件项）；Qwen Code "官方设置与扩展文档未列出输出风格"、Kimi Code "官方配置文档未列出输出风格；`[identity]` 仅改自称与协议标识"（均为未确认）；Qoder CLI "`outputStyle` · `--output-style` · `~/.qoder/output-styles/` 自定义 · 插件风格"（官方确认）。
- Claude Code 详情：入口为 `/config` Output style 菜单或任意设置 JSON 的 `outputStyle` 键（桌面 App 需手动写设置文件），独立 `/output-style` 命令 v2.1.73 弃用、v2.1.91 移除；内置风格 Default、Proactive、Explanatory、Learning，v2.1.237 新增 Concise（先给结果、省略铺垫与过程叙述，工作深度不变），官方文档页内置清单尚未列入 Concise；自定义风格位于 `~/.claude/output-styles`（用户）、`.claude/output-styles`（项目，自工作目录至仓库根逐级加载、重名取最接近者）、受管策略目录与插件 `output-styles/`；frontmatter 为 `name`、`description`、`keep-coding-instructions`（默认 false）、`force-for-plugin`（默认 false，为 true 时插件启用即覆盖用户选择，多个强制取最先加载者）；`/config` 菜单选择写入 `.claude/settings.local.json`；系统提示词会话启动时读取一次，改动需 `/clear` 或新会话生效。
- Codex 详情：`config.toml` 的 `personality` 键（`none`/`friendly`/`pragmatic`）设定默认沟通风格，仅对宣告 `supportsPersonality` 的模型生效，`/personality` 按线程或单轮覆盖；`features.personality` 开关 stable 默认开；保存在用户 `~/.codex/config.toml` 或项目 `.codex/config.toml`；无自定义风格文件机制，`developer_instructions`、`model_instructions_file`、`model_verbosity` 不属于风格预设。
- Qoder CLI 详情：`outputStyle` 顶层设置（兼容 `general.outputStyle`，同时配置时顶层优先）或 `--output-style` 参数（仅当前会话、优先于配置项、无需重启）；配置改动需重启 CLI；自定义 `.md` 风格位于 `~/.qoder/output-styles/`（全部项目）与 `<project>/.qoder/output-styles/`（当前项目），frontmatter 可选 `name`、`description`；插件风格以 `plugin-name:style-name` 引用，插件强制风格优先于 `outputStyle`、多个强制时第一个生效并记录警告；同名风格按内置→插件→用户级→项目级后者覆盖前者；官方示例取值 `concise`，未给出完整内置清单；设置文件为 `~/.qoder/settings.json`、`<project>/.qoder/settings.json`、`<project>/.qoder/settings.local.json`，按内置默认→用户→项目→本地→`--settings` 合并。
- Qwen Code 详情：设置文档（固定到提交 `081a96d86459`）无风格、personality 或语气类设置键，`output` 节仅含 `output.format`（text/json）与 `output.showTimestamps`；扩展文档（固定到提交 `a64d1291d2f6`）组件为 prompts、MCP servers、subagents、skills、custom commands、channels、上下文文件与设置，不含输出风格。
- Kimi Code 详情：`config.toml`（固定到提交 `157c84f5d1b0`）无风格、语气或 persona 配置键；最接近的 `[identity]` 只设自称（`name`，填充 `${product_name}`）与协议机器标识（`slug`）；`/theme`、`/custom-theme` 为配色主题；Plugin Agent 的 `systemPrompt` 属于 Agent 定义，不属于本字段。
- `site/data.js`：新增来源 `claude-output-styles`（官方文档页）、`claude-concise-v237`（更新日志固定到提交 `770933ea1ad2`）、`qwen-settings-current`（提交 `081a96d86459`）、`qwen-extension-intro-current`（提交 `a64d1291d2f6`）、`kimi-config-files-current`（提交 `157c84f5d1b0`）、`qoder-output-styles`、`qoder-settings`；新增 `extension-output-styles` 行。
- `site/extension-details.js`：新增 `extension-output-styles` 详情；`extension-plugins` 与 `extension-custom-commands` 的关联能力补录 `extension-output-styles`。
- `docs/09-版本与证据.md`：Claude Code 主要材料新增输出风格条目（核对日期保持 2026-08-20）；Codex 核对日期更新为 2026-08-20 并新增 `personality` 条目；Qwen Code、Kimi Code 核对日期更新为 2026-08-20 并新增输出风格复核条目；Qoder CLI 核对日期更新为 2026-08-20 并新增输出风格条目；官方来源表扩展系统列为五家分别补录对应链接。

## 证据版本

- Claude Code v2.1.237（Release 2026-08-20T00:54:41Z，更新日志提交 `770933ea1ad2`）CHANGELOG.md 原文："Added a built-in \"Concise\" output style: Claude leads with results and skips preamble and narration, while doing the work just as thoroughly. Select it under Output style in /config."
- Claude Code 官方输出风格文档（code.claude.com/docs/en/output-styles，2026-08-20 复核）："Output styles modify the system prompt to define role, tone, and output format without changing Claude's knowledge base."；内置风格 "Default"、"Proactive"、"Explanatory"、"Learning"（该页尚未列入 Concise）；选择方式 "Run `/config` and select **Output style** from the menu"、"Set the `\"outputStyle\"` field in a settings JSON file"；"Changes require `/clear` or a new session to take effect as the system prompt is read once at startup."；目录 "User scope: `~/.claude/output-styles`"、"Project scope: `.claude/output-styles`"、"Managed policy: `.claude/output-styles` inside the managed settings directory"、"Plugins: `output-styles/` directory within the plugin package"；"Project styles load from every `.claude/output-styles/` directory between the working directory and repository root; duplicates resolve to the file closest to the working directory."；"Terminal Menu Persistence: Saves selection to `.claude/settings.local.json` at the local project level."；frontmatter "`keep-coding-instructions`: Boolean (`false` default)"、"`force-for-plugin`: When `true`, applies the style automatically when the plugin is enabled. Overrides the user's `\"outputStyle\"` setting. If multiple plugins set this, the first loaded plugin wins."；"The standalone `/output-style` command was deprecated in v2.1.73 and removed in v2.1.91."
- Codex 官方配置参考（learn.chatgpt.com/docs/config-file/config-reference，2026-08-20 复核）：`personality` 键 "Default communication style for models that advertise `supportsPersonality`; can be overridden per thread/turn or via `/personality`."，取值 `none | friendly | pragmatic`，用户级 `~/.codex/config.toml`、项目级 `.codex/config.toml`；`features.personality` "Enable personality selection controls (stable; on by default)."；`/personality` 已收录于本仓库 Codex 命令目录（docs/01）。
- Qoder CLI Output Style 文档（docs.qoder.com/cli/output-styles，2026-08-20 复核）：输出风格调整 "tone, verbosity, and structure of Qoder CLI responses"，方式为 "appending instructions to the System Prompt"，"does not alter Qoder's core identity or security constraints"；配置键 "outputStyle"（顶层）与 "general.outputStyle"（兼容，"if configured in both places, the top-level setting takes precedence"）；命令行 "qoder --output-style concise" "only applies to the current session, takes precedence over configuration items, and does not require a restart"；自定义目录 "~/.qoder/output-styles/"（applies to all projects）、"<project>/.qoder/output-styles/"（applies only to the current project）；frontmatter `name`（defaults to the filename）、`description`（defaults to the first non-heading line of the body）；插件引用 "plugin-name:style-name"；"a plugin forced style takes precedence over the outputStyle setting. If multiple forced styles exist, the first one takes effect and a warning is logged"；同名优先级 built-in → plugin → User-Level → Project-Level（the latter overrides the former）；"After modifying outputStyle, you need to restart Qoder CLI for the changes to take effect."；未设置时 "Qoder uses its built-in default expression without appending any additional style"；示例取值 `concise`。
- Qoder CLI 配置文件与应用顺序文档（docs.qoder.com/cli/settings，2026-08-20 复核）：设置文件 "~/.qoder/settings.json"（User Level）、"<project>/.qoder/settings.json"（Project-Level）、"<project>/.qoder/settings.local.json"（Local Level），应用顺序 Built-in defaults → User → Project → Local → `--settings`；`outputStyle` 为顶层字符串 "Name of the active Output Style (requires restart). Compatible with the `general.outputStyle` syntax, with top-level taking precedence."
- Qwen Code 设置文档（github.com/QwenLM/qwen-code docs/users/configuration/settings.md，固定到提交 `081a96d86459`，2026-08-20 复核）：`output` 节仅含 `output.format`（默认 `"text"`，取值 `"text"`/`"json"`）与 `output.showTimestamps`（默认 false）；全文无 style/personality/tone/persona 设置键。扩展介绍文档（docs/users/extension/introduction.md，固定到提交 `a64d1291d2f6`，2026-08-20 复核）："Qwen Code extensions package prompts, MCP servers, subagents, skills and custom commands into a familiar and user-friendly format."，无输出风格组件。
- Kimi Code 配置文档（github.com/MoonshotAI/kimi-code docs/zh/configuration/config-files.md，固定到提交 `157c84f5d1b0`，2026-08-20 复核）：`config.toml` 顶层配置节（`providers`、`models`、`secondary_model`、`thinking`、`loop_control`、`token_counting`、`background`、`subagent`、`mcp`、`identity`、`tools`、`image`、`services`、`permission`、`hooks` 及顶层标量字段）无风格、语气或 persona 配置键；`identity.name` 为系统提示词中的自称、`identity.slug` 为协议字段机器标识。
