# Codex TUI 会话 Markdown 导出 `/export`

Codex 官方仓库在 2026-08-07 合入提交 `2801d12661be`（PR #37358），为 TUI 增加 `/export` 命令：把完整会话历史导出为结构化 Markdown，可选复制到剪贴板或保存为文件。最新 Release rust-v0.147.0 发布于 2026-08-07T01:41:49Z，早于该提交合入（02:40:17Z），官方 CLI 命令文档也尚未列出 `/export`，因此记录为条件项。矩阵的“导出会话”命令行和“会话导出”能力字段此前均记录 Codex 没有对应命令，本次更新这两个字段的 Codex 记录并新增来源固定到合入提交 SHA。

## 修正

- `cmd-export`（导出会话）矩阵 Codex 列由 `—` 更新为 `/export`（条件：main 分支，尚未发布）。
- `cmd-export` 详情 Codex 由“未确认”改为源码确认：主命令 `/export [path]`；不带参数打开 Export conversation 选择器（Copy to clipboard · Save to file）；Markdown 保留用户与助手消息、计划、推理、活动、图片标签、文件改动和 MCP 工具细节，并遵循推理可见性设置；保存默认文件名 `codex-session-<thread_id>.md`，无 thread ID 时 `codex-session.md`；不覆盖已存在文件；相对路径按当前工作目录解析，`~` 展开为主目录。
- `session-export`（会话导出）矩阵 Codex 列由“CLI 命令表未列出”更新为 `/export` · Markdown · 剪贴板（条件：main 分支，尚未发布）。
- `session-export` 详情 Codex 入口、行为、状态范围、自动行为、保存与保留、条件同步更新：只导出当前会话；历史分页加载，分页不可用时回退旧加载方式，ephemeral 会话使用可见 transcript；无会话或无内容时分别提示 “No active conversation to export.” 与 “No conversation content to export.”；命令只在 TUI 提供，`codex exec --json` 仍只输出单次非交互运行事件；写入使用 `persist_noclobber`；证据状态由“未确认”改为“源码确认”。
- 跨产品事实更新：五家都有显式会话导出入口，Codex 的入口以 main 分支合入时间标注。
- Slash 命令矩阵“导出会话”行 Codex 列由 `—` 更新为 `/export`（条件：main 分支，尚未发布）；Codex 命令目录新增 `/export`，并注明合入提交、尚未进入 Release、官方命令文档尚未列出。
- 来源新增 `codex-tui-export`，固定到合入提交 SHA；Codex 核对日期更新为 2026-08-07。
- 顺带修正 `docs/capabilities/README.md` 生成器中滞后的能力数：Slash 命令 28→29、权限与沙箱 8→9、扩展系统 7→8、任务执行与 Git 9→10，与 `site/data.js` 的 108 个能力字段和根 README 一致。
