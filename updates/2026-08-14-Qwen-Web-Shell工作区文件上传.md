# Qwen Code Web Shell 工作区文件上传

Qwen Code 官方仓库在 2026-08-13 合入提交 `a8bcaefea72d`（PR #8874，`feat(web-shell): support workspace file uploads`），为 `qwen serve` 自带 Web Shell 增加工作区文件直传：把普通文件拖入输入区，或在 `@` 文件面板选择“上传文件”，即可把本地文件写入工作区；多文件按顺序上传，带进度、取消、重名自动编号与服务端确认路径的行内文件标签。上传走独立的二进制路由（`POST /file/upload` 与 `/workspaces/:workspace/file/upload`），单文件上限 50 MiB，与 5 MiB 文本写入上限相互独立，并由 daemon 的 `workspace_file_upload` 能力通告控制入口显隐。该提交随 v0.21.12-preview.3（2026-08-14 发布）进入预览通道，最新稳定版 v0.21.11 尚未包含。同时核对发现：2026-08-10 合入的图片拖拽/粘贴输入（提交 `e46586782cf8`）已随 v0.21.9（2026-08-10 发布）进入稳定通道（v0.21.9 发布说明明确列出 #8696），矩阵此前“main 分支，尚未发布”的表述一并更正。矩阵 `surface-web` 字段更新 Qwen Code 矩阵结论与详情记录，其余四家 Web Surface 文档重新核对后仍无浏览器侧文件上传或图片附件能力。

## 修正

- `surface-web`（Web 界面）矩阵 Qwen Code 列由 “`qwen serve` 内置 Web Shell；条件：图片拖拽/粘贴输入（main 分支，尚未发布）” 更新为 “`qwen serve` 内置 Web Shell；条件：图片拖拽/粘贴输入（v0.21.9 起）· 工作区文件上传（v0.21.12-preview.3 预览通道）”。
- `surface-web` 详情 Qwen Code 记录：入口补充文件上传经输入区拖入普通文件或 `@` 文件面板“上传文件”进入，图片输入状态更正为 v0.21.9 起；协议补充文件上传走独立二进制路由、要求 `Content-Type: application/octet-stream`（否则 415）、不复用文本写入路由、v1 无 ACP-HTTP 对等上传方法；行为补充拖放上传到目标工作区根目录、`@` 面板上传到当前浏览目录、多文件顺序上传带进度与取消、重名在扩展名前插入 ` (N)` 编号（最多 1000 次尝试）、上传从不覆盖已有文件、仅含受支持图片的批次仍走图片附件流程；状态补充上传进度显示在输入区上方、成功条目三秒后消失、结果成为可移除的行内文件标签（服务端确认路径）、TypeScript SDK `uploadWorkspaceFile` 支持进度回调、取消与超时；条件补充图片输入随 v0.21.9 发布、文件上传于 2026-08-13 合入 main 并随 v0.21.12-preview.3 预览通道发布（稳定通道尚未发布）、`workspace_file_upload` 能力通告与旧 daemon 隐藏入口、50 MiB 单文件上限（`MAX_UPLOAD_BYTES`，与 `MAX_WRITE_BYTES` 独立且不可配置）、单批 100 文件、文件名 255 字节、4 并发（饱和 429 `upload_busy`）、超限 413 `file_too_large`、不受信任/未知/draining 工作区 403 且不回退、`0o600` 原子发布、取消尽力而为、不支持断点续传/分块/文件夹/原地覆盖、官方用户文档尚未描述这两种输入方式；来源新增固定到提交 SHA 的文件上传提交、设计文档、上传策略源码、能力源码与 v0.21.12-preview.3 发布说明，并复用 v0.21.9 发布说明来源记录图片输入的发布状态。
- `surface-web` 跨产品事实更新：Qwen Web Shell 自 v0.21.9 支持图片拖拽/粘贴输入与图片-only prompt，自 v0.21.12-preview.3 预览通道支持本地文件直传进工作区；Claude、Codex、Kimi、Qoder 的官方 Web 文档未列浏览器侧图片拖拽、粘贴或本地文件上传（Claude 可由 CLI `claude --cloud` 把整个本地仓库打包上传到云会话，不属于浏览器侧文件上传）。
- `site/data.js` 新增五个来源条目（文件上传提交、设计文档、上传策略源码、能力源码、v0.21.12-preview.3 发布说明）。
- `docs/09-版本与证据.md`：Qwen Code 核对日期更新为 2026-08-14；主要材料中图片输入更正为随 v0.21.9 发布，并新增工作区文件上传条目；Headless、SDK 与多端来源表 Qwen Code 服务列新增 v0.21.9 发布说明、文件上传提交、文件上传设计文档与 v0.21.12-preview.3 发布说明四个链接。
