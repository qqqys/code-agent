# 并行 Worktree：Codex CLI 托管 Worktree 转正，并复核其余四家

Codex 官方 Release 与源码确认：CLI/TUI 自 rust-v0.154.0（2026-09-09）起提供托管 Git Worktree，rust-v0.156.0（2026-09-22）起默认开启。矩阵 `execution-worktree`（并行 Worktree）字段 Codex 列此前写的是"桌面 App Worktree；CLI 无对应隔离"、证据状态"条件项"，该结论已被一手资料推翻，本次改写为 CLI 入口、目录布局、创建与删除行为、门禁条件和版本时间线。同一字段顺带复核其余四家：Claude Code 官方 Worktrees 文档新增 v2.1.247/v2.1.274/v2.1.277/v2.1.281 四批行为；Qwen Code v0.24.7 文档改写了过期清扫守卫与 caller-owned `working_dir` 后台规则；Kimi Code 2.1.1 官方文档仍无 Worktree 入口，但源码确认 `/tower` 模式让每个 worker 独占 `.tower/worktrees/` 下的一个 git worktree；Qoder CLI 现行文档把入口写成 `qoder --worktree [name]`（隔离执行并把结果并回主分支），此前引用的 `en/cli/using-cli` 页核对时返回 404，Concurrent Job 表述改为未确认。

## 修正

- `execution-worktree` 矩阵五列全部更新：
  - Codex 由"桌面 App Worktree；CLI 无对应隔离"（条件项）改为 "`--worktree` · `/worktree` 托管检出（rust-v0.154.0 实验性、0.156.0 起默认开启）"，证据状态改为"官方确认"。
  - Claude Code 补上"主检出写入阻断"。
