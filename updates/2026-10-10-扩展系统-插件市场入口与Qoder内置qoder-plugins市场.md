# 插件分发：Qoder CLI 1.1.66 内置 `qoder-plugins` 插件市场，五家市场入口、市场管理命令与内置默认市场补齐

Qoder CLI 官方 [Release Notes](https://docs.qoder.com/release-notes/qoder-cli) 的 CLI 1.1.66（October 8, 2026）小节标题为 “Built-in plugin marketplace and stability fixes”，条目逐字为 “Added the built-in qoder-plugins plugin marketplace”。这是本仓库尚未记录的一手确认新功能：Qoder CLI 第一次自带一个插件市场，不再要求用户先 `marketplace add` 才能浏览已发布插件。

本仓库 `extension-plugins`（插件分发）字段此前只记了各家的管理入口一句话，Qoder 列还写着已过期的可执行名 `qodercli plugins`，五家都没有记录市场（marketplace）这一层：市场来源形状、市场管理子命令、是否有内置默认市场、插件 ID 的限定写法、安装作用域与重载方式都缺失。本次只处理 `extension-plugins` 一个字段，补录 Qoder 的内置市场与 `qoder plugins` 子命令组，并把其余四家的市场入口逐项核对到当前一手资料。
