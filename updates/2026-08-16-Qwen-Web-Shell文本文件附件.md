# Qwen Code Web Shell 文本文件附件

Qwen Code 官方仓库在 2026-08-15 合入提交 `34cc1c3ede69`（PR #9180，`feat(web-shell): support text file attachments in the composer`），为 `qwen serve` 自带 Web Shell 输入区增加文本文件附件：粘贴受支持的文本文件成为可移除附件 chip，随 prompt 以独立文件对象提交，ACP 会话侧嵌入为带 `attachment:///` URI 的文件引用资源块。接受范围由 `TEXT_FILE_EXTENSIONS` 扩展名白名单、`TEXT_FILENAMES` 知名文件名（Dockerfile 等）与 `text/*`/`TEXT_MIME_TYPES` 共同决定，扩展名与文件名回退优先于 OS MIME 绑定（修正 Windows 上 `.ts`/`.mts` 被绑为 video/mp2t、`.csv`/`.tsv` 被绑为 Excel 的问题），解码后含 NUL 字符的二进制内容按 `unsupported` 拒绝；单条 prompt 的文本附件共享 512 KiB 累计预算，附件随重试血缘恢复。该提交合入 main，但最新预览发布 v0.21.12-preview.5（2026-08-16，自 release 分支切出）未包含该提交，预览与稳定通道均未发布。拖拽路由规则不变：工作区上传入口可用时，含任一非图片文件的拖拽批次仍整批走工作区上传，文本附件经粘贴进入。官方用户文档（main 分支 qwen-serve.md）仍把 prompt 路径图片/文件附件列为已知缺口，未描述文本附件。矩阵 `surface-web` 字段更新 Qwen Code 矩阵结论与详情记录；其余四家 Web Surface 文档按 2026-08-14 核对未列浏览器侧图片/文件附件输入，本次运行未发现新增相关官方变更，维持原记录。
