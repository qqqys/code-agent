# 运行中会话列表能力字段与 Qwen `qwen sessions ps`

Qwen Code 官方仓库在 2026-08-17 合入 PR #8969（`feat(core): add a live-session registry and qwen sessions ps`，合并提交 `a1e046eb6c5546e6aab2a004367e67c2af1673fd`），新增 CLI 命令 `qwen sessions ps`，基于 `~/.qwen/sessions/` 实时进程登记表列出本机正在运行的交互式会话；该功能随 v0.21.14（2026-08-19T02:46Z 发布）发布，发布说明 Highlights 与 Features 均列出本项（#8969、#9261、#9366）。矩阵此前没有任何字段区分"运行中会话列表"与"历史会话恢复"，本次新增 `session-live-list`（运行中会话列表）字段并覆盖五家产品。同一发布说明明确列出 `/advisor`，矩阵中 `/advisor` 的"合入 main 尚未发布"状态同步更新为"v0.21.14 起"。

## 修正

- 新增能力字段 `session-live-list`（会话与上下文域）：列出本机当前正在运行的交互式会话，区别于已保存的历史会话。矩阵结论分别为 Claude Code "Agent view 与 `claude agents --json` 列出运行中会话；会话选择器以 `bg` 标记后台会话"、Codex "官方命令表未列出运行中会话列表；`codex resume` 选择已保存会话"、Qwen Code "`qwen sessions ps` · `--json` JSON Lines（v0.21.14 起）"、Kimi Code "`/sessions` 仅列出已保存历史会话；官方文档未列出运行中会话入口"、Qoder CLI "`/resume` 恢复历史会话；官方命令表未列出运行中会话列表"。
- Qwen Code 详情：`qwen sessions ps` 默认输出 NAME、PID、AGE、DIRECTORY 表格，空列表输出 `No other interactive Qwen Code sessions are running.`；`--json`（默认 `false`）按 JSON Lines 输出 `schemaVersion`、`pid`、`procStart`、`pidNs`、`sessionId`、`cwd`、`name`、`startedAt`、`qwenVersion` 原始字段，stdout 无其他输出；登记表位于 `~/.qwen/sessions/`（目录 0700、`<pid>.json` 记录 0600、`noFollow` 写入），交互会话启动注册、退出注销，Headless（`qwen -p`）不注册；Linux 以 `<boot_id>:<starttime>` 与 PID 命名空间作进程身份并在不可读时拒绝注册，非 Linux 退化为 PID 存活检查；失效记录发现即清除（清除前重读防竞态），外部身份或更高 schema 记录跳过不清除；同版 Daemon 新增受信任 `GET /workspaces/:workspace/sessions/live-state` 内存快照（PR #9261），Web Shell 改为消费该端点（PR #9366）。
- Claude Code 详情：官方 Sessions 文档把 agent view 与 `claude agents --json` 输出描述为运行中会话的列表；会话选择器默认列当前 Worktree 会话（含 `bg` 后台会话），`Ctrl+W`/`Ctrl+A`/`Ctrl+B` 扩展或过滤范围，未命名会话默认名称为工作目录名加两位字符后缀。
- Codex、Kimi Code、Qoder CLI 详情记录边界：Codex 命令表仅列 `codex resume`/`codex exec resume`/`codex fork`/`codex cloud list` 与 `/archive`，Kimi `/sessions`（别名 `/resume`）与 `kimi --session` 仅浏览历史会话，Qoder `/resume`/`/continue` 面向历史记录；三家均保留"未确认"，不据此推断底层能力不存在。
- `/advisor` 发布状态更新：`cmd-collaboration`（多模型或多代理模式）矩阵 Qwen Code 列由 "`/advisor`（条件：合入 main 尚未发布）…" 更新为 "`/advisor`（v0.21.14 起）…"；详情的 Qwen Code 记录行为与条件同步改为随 v0.21.14（2026-08-19 发布）发布，来源补充 v0.21.14 发布说明；跨产品事实同步改写；`docs/01-Slash命令矩阵.md` 对照表与硬编码命令说明同步改为随 v0.21.14 发布。
- `site/data.js`：新增来源 `qwen-sessions-ps-commit`（合并提交 `a1e046eb6c55`）、`qwen-sessions-ps-docs`（该提交时点的 `docs/users/features/commands.md`）、`qwen-sessions-ps-source`（`packages/cli/src/commands/sessions/ps.ts`）、`qwen-session-registry-source`（`packages/core/src/services/session-registry.ts`）、`qwen-v02114-release`（v0.21.14 发布说明）。
- `docs/09-版本与证据.md`：Qwen Code 核对日期更新为 2026-08-19，主要材料新增实时会话登记表条目并把 `/advisor` 改为随 v0.21.14 发布；Claude Code 主要材料补充会话选择器与运行中会话列表条目；官方来源表 Qwen 会话与上下文列新增登记表提交、命令文档、命令源码、登记表源码与 v0.21.14 发布说明链接。
