# Qwen Code Fork 工具执行限制

核对 Qwen Code commit `079ce5346af7`（feat(agent): add fork tool execution allowlist #8066）中新增的 `fork_tools` 功能。

## 修正

- Qwen Code `agent-tools` 矩阵结论从 "`tools`" 更新为 "`tools`；Fork 可用 `fork_tools` 限制执行"。
- `fork_tools` 是调用 Fork 时传入的数组参数，限制 Fork 实际可执行的工具，不改变模型可见的工具声明。
- 接受精确工具名（如 `read_file`、`grep_search`）、MCP Server 模式（如 `mcp__github`）和前缀通配（如 `mcp__github__read_*`）；不接受单独的 `*`。
- 省略时不限制 Fork 工具执行；空数组拒绝全部工具调用。
- 未匹配的工具调用在调度或审批前被拒绝。
- 列出 `run_shell_command` 只允许该工具进入正常权限检查，不预批准任何 Shell 命令。
- `fork_tools` 是调用方提供的每次调用限制，不是管理员强制的安全沙箱。
- Claude Code Fork 跳过所有工具过滤器，直接获得主会话完整工具池；Codex、Kimi Code 与 Qoder CLI 当前未确认等价的 Fork 调用时工具限制。
- Qwen Code Subagent 来源从 `7db57552e33a` 固定到 `079ce5346af7`。
