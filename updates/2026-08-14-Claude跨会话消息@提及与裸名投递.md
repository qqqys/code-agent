# Claude Code 跨会话消息 @ 提及与裸名投递

Claude Code v2.1.232（2026-08-13 发布）扩展跨会话消息：提示词输入 `@` 加会话名开头字母可提及本机其他运行中会话，Claude 直接用 `SendMessage` 联系该会话；`SendMessage` 对恰好匹配一个运行中会话的裸名直接投递，不再先要求确认 ref；同机交互会话保持唯一名称；`/config` 新增 `Messages from your other sessions` 与 `Dialog expiry` 两行。v2.1.229（2026-08-12 发布）为 `ListAgents` 输出增加 `offline`/`cloud` 状态标签。矩阵 `session-messaging` 字段此前只记录到 v2.1.225 的按名称发起行为，本次把 v2.1.229/v2.1.232 行为补入 Claude Code 记录。其余四家在该领域无同类变化：Codex 与 Kimi Code 的官方命令表和文档仍未列出会话间消息，Qwen Code `send_message`/`list_agents` 仍限当前会话后台 Agent，Qoder CLI Agent Teams 仍为单 TUI 会话内，结论保持不变。

## 修正

- `session-messaging` 字段 Claude Code 矩阵结论由 "`/list-agents` · `/peers` · `SendMessage`/`ListAgents` · `crossSessionInbound`" 改为 "`/list-agents` · `/peers` · `SendMessage`/`ListAgents` · `@` 会话名提及 · `crossSessionInbound`"。
- Claude Code 详情补入：v2.1.232 起提示词输入 `@` 加会话名开头字母从补全列表选择本机运行中会话进行提及（单独输入 `@` 不出现会话行），Claude 无需先列出会话即可用 `SendMessage` 直接联系；`SendMessage` 对恰好匹配一个运行中会话的裸名直接投递，多个会话同名或无法核查全部运行位置时列表每行附加短标识符并按标识符寻址，提及或点名命中多个运行中会话时先询问发送给哪一个；v2.1.229 起 `ListAgents` 把云端会话标为 `cloud`、断开的 Remote Control 会话标为 `offline`；`/list-agents` 输出显示每个本地会话的工作目录；v2.1.232 起同机交互会话保持唯一名称（启动、重命名或恢复时名称已被其他运行中会话占用，原会话保留名称，新会话改名为 `name-word-word` 变体并收到提示；旧版本或自动生成名称仍可能重名）；收到的消息以发送方会话名展示并保留，发往其他机器 Remote Control 会话的消息显示为本会话的 Remote Control 名称；`/config` 的 `Messages from your other sessions` 行设置 `crossSessionInbound`（v2.1.232 起，managed settings 或 `--settings` 已设置该键时不显示，拒绝 `/config crossSessionInbound=value` 简写），`Dialog expiry` 行设置 `dialogExpiry`；`dialogExpiry` 设为 `"never"` 时默认保留的消息保留到会话结束，`-p` 会话默认保留的消息同样按 `dialogExpiry` 到期丢弃。
- 新增来源：`claude-messaging-v229`（更新日志，固定提交 SHA `992381936817`）、`claude-messaging-v232`（更新日志，固定提交 SHA `1f6015b5d578`）。
- `docs/09-版本与证据.md`：Claude Code 核对日期更新为 2026-08-14，主要材料补充 v2.1.229 状态标签与 v2.1.232 跨会话消息扩展；官方来源表 Claude Code 会话与上下文列新增 v2.1.229、v2.1.232 更新日志链接。
- `site/data.js` 的 `updatedAt` 更新为 2026-08-14，`README.md` 核对日期同步；`npm run generate` 重新生成 `docs/04-会话与上下文矩阵.md` 与 `docs/capabilities/sessions/`（`session-messaging.md` 内容更新，各页核对日期随 `updatedAt` 更新）。
- 能力字段总数不变（110 个），`README.md` 计数无需调整。

## 证据版本

- Claude Code 官方更新日志 v2.1.232（提交 `1f6015b5d578`，2026-08-13T23:29:53Z）原文："Type `@` in the prompt to mention another Claude session by name; Claude then uses `SendMessage` to reach that session directly"、"`SendMessage` now delivers to a bare name that exactly matches one live session, instead of asking to confirm with a ref first"、"Interactive sessions on one machine now keep unique names: starting or renaming a session to a name another live session already uses gives it a `name-word-word` variant and tells you"、"Added `/config` rows for \"Dialog expiry\" and \"Messages from your other sessions\" (cross-session inbound accept/hold/refuse)"。
- Claude Code 官方更新日志 v2.1.229（提交 `992381936817`，2026-08-12T20:56:14Z）原文："`ListAgents` now marks disconnected Remote Control sessions as `offline` and labels your cloud sessions as `cloud`"。
- Claude Code 官方文档 [Message your other Claude Code sessions](https://code.claude.com/docs/en/cross-session-messaging)（2026-08-14 抓取）：`@` 提及要求 v2.1.232 及以上；"Once you type at least one letter after the `@`, Claude Code suggests your other live sessions on this machine; after a bare `@`, session rows don't appear"；"When more than one live session answers to the mentioned name, Claude asks you which one you mean before sending"；"One session answers to the name: Claude Code delivers the message on the name alone"；"Several sessions share the name, or Claude Code couldn't check everywhere your sessions run: Claude adds a short identifier to each row of its listing and uses the identifier in the address"；唯一名称段落 "Claude Code leaves the name with the session that already has it and renames yours to a variant" 与 "Sessions can still share a name, for example when one of them runs an earlier version of Claude Code or the shared name is one Claude Code generated"；`/config` 的 `Messages from your other sessions` 行要求 v2.1.232 及以上，"doesn't appear while managed settings or the `--settings` flag sets the key"，"Claude Code rejects the `/config crossSessionInbound=value` shorthand for this key"；"Set `dialogExpiry` to `\"never\"` to keep default-held messages until the session ends"；"A `-p` session can't show the approval dialog. When the inbound default holds a message there, Claude Code keeps it for the same `dialogExpiry` deadline the dialog uses, five minutes by default"；`/list-agents` 输出显示每个本地会话的工作目录，云端会话标为 `cloud`，断开的 Remote Control 会话标为 `offline`。
- 其他四家本次无同类变化：Codex 官方命令表与文档目录未列出会话间消息；Kimi Code 官方 Slash 命令表未列出会话间消息命令；Qwen Code `send_message`/`list_agents` 仍限当前会话后台 Agent（原记录来源提交 `412eae24b48f`，结论不变）；Qoder CLI Agent Teams 仍为 beta 且限于单个 TUI 会话（原记录来源文档页，结论不变）。
