# Qwen Code 原生多代理协调（/coordinate 与 Agent Team）

Qwen Code PR #8804（提交 `8858d4340bbbb46f693dd09767aaaadc7ec7cc9b`，2026-08-12T17:39Z 合入 main）新增原生多代理协调：随产品提供的 `/coordinate` Skill 与 Agent Team 运行时。`/coordinate <goal>` 由 Leader 把目标拆分为最多 3 个独立工作流；调查队友被运行时强制只读工具集（不能执行 shell 命令、写文件或继续派生 Agent）；Leader 可创建 1 个 Git Worktree 并固定 1 名写手队友，自己保持当前分支唯一合并权；队友共享任务清单、经既有团队工具（`send_message`、`task_list`、`task_update`）互发消息，并显示在既有 Agent View 页签。完整团队协作需将 `experimental.agentTeam` 设为 `true` 并重启，或以 `QWEN_CODE_ENABLE_AGENT_TEAM=1` 启动；未启用时 `/coordinate` 退回普通前台 Agent 做只读并行调查（仅委派、不协作）。该提交晚于最新 Release v0.21.11-preview.0（2026-08-12T00:55Z，基于 `a64d1291d2`），记录为 main 分支条件项。本次更新 `cmd-collaboration`（多模型或多代理模式）字段的 Qwen Code 记录。
