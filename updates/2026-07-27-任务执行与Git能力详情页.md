# 增加任务执行与 Git 能力独立详情页

任务执行与 Git 从一张混合表拆成 9 个可打开的能力页：文件读写、Shell 执行、代码搜索、后台任务、代码 Review、Git 操作、Pull Request、CI 自动化和并行 Worktree。

本次逐产品补充入口与工具、核心机制、执行行为、运行范围、后台与并发、Git 与平台联动、状态与产物、条件和官方来源，并同步修正以下旧结论：

- Qwen Code `/review` 是随产品提供的内置 Skill，可审本地变化、指定文件和 Pull Request；同仓 PR 使用隔离 Worktree。
- Qwen Code Worktree 同时覆盖 `--worktree`、会话内 enter/exit 工具和 Agent 隔离，不再只记录 Subagent 字段。
- Codex 的托管 Worktree 当前属于 ChatGPT 桌面 App，不再写成“Subagent 文档未确认”。
- Qoder CLI 除 Agent 隔离外，还提供 `--worktree` Concurrent Job、任务列表和删除入口。
- Kimi Code 的文件、Shell、搜索和后台任务按当前官方工具表补充参数与行为；当前公开 CLI/Agent Surface 没有内置 Review、CI Workflow 或 Worktree 管理入口。
- Git 操作、Pull Request 和 CI 自动化拆成三个字段，避免把“能运行 gh”和“有官方 GitHub 工作流”写成同一能力。

网页与 Markdown 使用同一份矩阵数据和详情记录。
