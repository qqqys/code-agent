# Codex 远程插件搜索与 extension-plugins 字段深化

Codex 在 2026-08-01 的提交中实现了 app-server 的 `plugin/search` JSON-RPC，可直接查询远程插件服务。本次把这个一手确认的新能力并入现有 `extension-plugins` 字段（不新增同义字段），并在 Codex 详情中补足入口、行为、适用界面、功能开关与开发状态等条件。

## 修正

- `extension-plugins` 矩阵 Codex 列保持 `/plugins`（默认 Surface 为 CLI，远程搜索不是 CLI 命令）。
- Codex 详情记录新增：`/plugins` 浏览器可搜索或浏览统一插件目录；app-server 另有 `plugin/search` JSON-RPC，绕过本地目录缓存直接搜索远程服务，接受 `searchTerm`、可选 `global`/`workspace`/`personal` scope 与 `cursor`/`limit`，返回带 marketplace 限定的插件摘要并以 `nextCursor` 透传分页令牌。
- 条件补充：`plugin/search` 受 `remote_plugin` 与 `plugin_sharing` 功能开关控制——`remote_plugin` 关闭时省略 scope 按 `workspace` 处理、`global`/`personal` 返回空页且不查询远程服务，`plugin_sharing` 关闭时共享/私有工作区结果在取回后被过滤；该端点不与已安装快照联表，返回项 `installed` 恒为 `false`，官方标注 under development、do not call from production clients yet。
- 适用界面补充：远程插件搜索只在 app-server JSON-RPC 暴露，不在 CLI、IDE 扩展或移动端。
- 跨产品事实新增：远程插件搜索目前只有 Codex 在 app-server 提供，其余四家插件发现仍走本地目录或 `/plugins` 浏览器。
- 新增来源 `codex-plugin-search`，固定到实现提交 SHA。
