# 桌面与浏览器控制能力字段

Kimi Code 在 2026-08-04 的官方仓库提交中把 Kimi Computer Use（`kimi-cu`）与 Kimi WebBridge（`kimi-webbridge`）作为 `/plugins` 内置能力条目合入主分支（changeset 标记为 minor，尚未进入发布版本）。矩阵此前没有任何字段记录产品内置的桌面 GUI 自动化或真实浏览器控制能力，本次新增 `execution-computer-use`（桌面与浏览器控制）字段，覆盖五家产品，并按 Surface 区分内置工具与 MCP 扩展。

## 修正

- 新增能力字段 `execution-computer-use`（执行与 Git 域）：Qwen Code 与 Kimi Code 在 CLI 内提供内置桌面/浏览器控制；Codex 的 Computer Use 仅在 ChatGPT 桌面 App Surface；Claude Code 与 Qoder CLI 的官方内置工具表没有同类工具，官方路径为 MCP 扩展。
- Kimi Code 详情：v2 CLI 的 `/plugins` 面板内置 `kimi-cu`（仅 macOS：`KimiCU.app`、同名插件与 `ai.kimi.cu.service` launchd 服务，后台 GUI 自动化，需辅助功能与屏幕录制 TCC 权限）与 `kimi-webbridge`（macOS arm64/x64、Linux arm64/x64、Windows x64：`~/.kimi-webbridge/bin/` 守护进程加官方浏览器控制插件，控制带登录态的真实浏览器，浏览器扩展为可选手动安装）；安装幂等、逐项就绪检测、报告缺失手动步骤并支持重试；条目由客户端按发布版本注入默认 Official marketplace。该提交合入时 0.32.0 已发布，功能未进入发布版本，记录为条件项。
- Qwen Code 详情：`computer_use__*` 内置工具默认开启（`tools.computerUse.enabled` 可关闭，重启生效），`cua-driver` 二进制首次使用下载到 `~/.qwen/computer-use/`，预构建二进制覆盖 macOS、Linux x86_64、Windows x86_64；动作类工具需审批；`page` 工具操作 Chrome、Brave、Edge、Safari 与 Electron 应用中的页面；另有 `maxImageDimension`、`idleTimeoutMs` 配置与轨迹录制/重放。
- Codex 详情：Computer Use 在 ChatGPT 桌面 App 安装启用，经 `@Computer`/`@AppName` 调用；macOS 支持后台与锁屏（Locked use）使用，Windows 仅活动桌面并接管前台输入；Windows 允许列表为 `$CODEX_HOME/config.toml` 的 `[computer_use.windows] always_allowed_app_ids`，管理员可用 `requirements.toml` 的 `[features].computer_use = false` 禁用；CLI 未提供同类内置工具。
- Claude Code 与 Qoder CLI 详情记录边界：官方内置工具表均未列出桌面控制、鼠标键盘或浏览器控制工具；`WebFetch`/`WebSearch` 只抓取内容或返回搜索链接，不操作界面；自定义工具经 MCP 接入。
- 新增来源 `codex-computer-use`（官方 Computer Use 文档）、`qwen-computer-use`（固定到文档提交 SHA）与 `kimi-builtin-capabilities`（固定到实现提交 SHA）。
- `docs/capabilities/README.md` 生成器中的能力数同步修正：Slash 命令 28 → 29、扩展系统 7 → 8（与实际详情文件数一致），任务执行与 Git 9 → 10。

## 证据版本

- Kimi Code 官方仓库提交 `0abcd00f7fd3e3cbf087509ffef1c54a6f8d396d`（`feat(cli): add built-in Computer Use and WebBridge capabilities (#2407)`，2026-08-04）：changeset 声明 “Add Kimi Computer Use and Kimi WebBridge as built-in official marketplace entries in the v2 CLI. Installing from `/plugins` sets up the latest managed runtime and plugin together, reports incomplete manual steps, and supports retrying interrupted setup.”；`kimiCu.ts` 记录 `kimi-cu` 仅 `darwin`、安装 `KimiCU.app` 与 `ai.kimi.cu.service`、就绪检测含插件/应用/服务/权限（`xpc-ping` 校验 `accessibility` 与 `screenRecording`）；`kimiWebbridge.ts` 记录守护进程路径 `~/.kimi-webbridge/bin/`、start-if-down（与 Kimi Work 共存）、可选浏览器扩展（`extension_connected`）与 `~/.kimi-code/skills/`、`~/.agents/skills/` 下旧技能副本检测。
- Kimi Code 官方 Release：0.32.0 发布于 2026-08-04T07:14Z，早于该提交合入（09:59Z），发布说明未包含该功能。
- Qwen Code 官方仓库文档 `docs/users/features/computer-use.md`（提交 `0907edb909706cf7589f94723b26572eb1dd9512`）：默认开启、`tools.computerUse.enabled`/`maxImageDimension`（默认 `-1`）/`idleTimeoutMs`（默认 `300000`）、二进制位于 `~/.qwen/computer-use/`、macOS/Linux x86_64/Windows x86_64 预构建、macOS 需辅助功能与屏幕录制权限、动作工具需审批。
- Codex 官方 Computer Use 文档（learn.chatgpt.com/docs/computer-use）：ChatGPT 桌面 App Surface、`@Computer`/`@AppName` 调用、macOS 屏幕录制与辅助功能权限及 Locked use、Windows 活动桌面限制、Plugins > Computer Use 安装与启用、Chrome/Excel/PowerPoint 集成。
- Codex 官方配置参考：`computer_use.windows.always_allowed_app_ids` 为 Windows 允许列表，列表外应用需审批。
- Claude Code 官方工具参考（tools-reference）：内置工具表无桌面或浏览器控制工具，自定义工具经 MCP Server 添加。
- Qoder CLI 官方 SDK Reference 内置工具表：Bash、Read、Edit、Write、Glob、Grep、WebFetch、WebSearch、Agent、NotebookEdit、TaskOutput、TaskStop 等，未列桌面或浏览器控制工具。
