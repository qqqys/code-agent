# Qwen Code `/review --topology minimal` 单遍 A/B 对比臂

Qwen Code 于 2026-08-25 经 PR #9919（合并提交 `43d7596d9d4ea44b9fc5b305d01a313d837c8c81`）把 `--topology` 接入 `/review` 内置 Skill 的参数解析：`minimal` 选择单遍 A/B 对比臂，评审不再走多 Agent 管线，而是 orchestrator 在自己的上下文里对 diff 做一次认真的资深工程师式通读，至多报告 15 条 findings 且每条必须带一个具体失败场景，跳过 Subagent 扇出、验证、反向审计、构建/测试与发布，仅终端输出、不产生 verdict。拓扑与 effort 正交：解析裁决把 `topology`/`topologySource` 与 target、effort 并列，`minimal` 是不同形状的审查而不是同一审查的某一深度，选中后完全覆盖 effort 分发；DESIGN.md 的 LLM 调用预算一节把该臂定价为 0 个 subagent 调用。该臂是 issue #9783 提出的 A/B 基线所需的可对比臂，用于把同一批 PR 分别经 `--effort high` 全量管线与极简提示词运行后按模型对比 recall/precision；PR 明确不引入基于模型的自动路由。`--topology` 只在 `/review` Skill 参数字符串中解析，Headless 包装 `qwen review run` 不接受、不透传该旗标。该提交合入 main 尚未发布，官方用户文档 `docs/users/features/code-review.md` 尚未同步。其余四家当前一手资料未列出同类审查拓扑选择入口。
