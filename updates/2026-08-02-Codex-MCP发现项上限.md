# Codex MCP 发现项收集上限与 extension-mcp 字段深化

Codex 在 2026-08-01 的提交中把 MCP 工具、资源与资源模板分页发现结果的收集上限从 1,024 提高到 2,048（常量 `MAX_MCP_CATALOG_ITEMS`，位于 `codex-rs/codex-mcp/src/pagination.rs`）。本次把这个一手确认的默认行为并入现有 `extension-mcp` 字段的 Codex 详情（不新增同义字段），并在跨产品事实中记录这是当前唯一公开同类上限的产品。

## 修正

- `extension-mcp` 矩阵 Codex 列保持 `/mcp` · STDIO/HTTP（发现项上限不是传输或命令，不进矩阵短结论）。
- Codex 详情的条件与边界新增：MCP 工具、资源与资源模板的分页发现结果合计最多收集 2,048 项（`MAX_MCP_CATALOG_ITEMS`，原 1,024），超出部分不会进入工具列表。
- 跨产品事实新增：Codex 公开了 MCP 发现项收集上限；其余四家当前一手资料未列出同类上限。
- 新增来源 `codex-mcp-catalog`，固定到实现提交 SHA。
