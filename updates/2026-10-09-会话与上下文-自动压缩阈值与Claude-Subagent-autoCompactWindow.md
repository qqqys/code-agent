# 手动压缩：Claude Code v2.1.296 给 Subagent 定义加 `autoCompactWindow`，五家自动压缩阈值与开关补齐

Claude Code 官方仓库 `CHANGELOG.md`（main 分支，固定到提交 `2301018b1f61073c501a8e7a4813ef48c239163b`，2026-10-09T19:28:36Z，只改 `CHANGELOG.md` 与 `feed.xml`）在 `## 2.1.296` 段下逐字写明 “Added `autoCompactWindow` to subagent frontmatter and `--agents` definitions, so a subagent can auto-compact earlier than the main conversation's window”。对应 Release [v2.1.296](https://github.com/anthropics/claude-code/releases/tag/v2.1.296) 发布于 2026-10-09T19:28:59Z。这是本仓库尚未记录的一手确认新功能：Subagent 定义第一次可以带自己的自动压缩窗口，比主会话窗口更早压缩。

本仓库 `session-compress`（手动压缩）字段此前只记录了五家的手动命令，`includes` 里虽然列了「自动压缩触发」，但只有 Codex 的 `model_auto_compact_token_limit`、Qwen Code 的 `context.autoCompactThreshold` 默认 0.85 与 Kimi Code 的 `loop_control.reserved_context_size` 三项一句话结论，Claude Code 的自动行为只写「上下文接近容量时自动压缩；具体触发受模型窗口与当前上下文组成影响」，Qoder CLI 只写「未公开 CLI 自动压缩的具体阈值」。本次只处理 `session-compress` 一个字段，补录 Claude Code 的整套窗口入口（`/autocompact`、`--autocompact`、`autoCompactWindow`、`autoCompactEnabled` 与四个环境变量）、默认阈值与优先级、v2.1.296 的 Subagent 窗口，并把其余四家的阈值语义、默认值、环境变量覆盖与 Subagent 级配置有无逐项核对到当前一手资料。
