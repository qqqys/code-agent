# 桌面端：Kimi Code 官方桌面端与 `kimi app`/`kimi install-desktop` 入口，Claude 与 Codex 桌面端 Linux 版，Qwen 桌面壳改为 Tauri 2

`surface-desktop`（桌面端）字段本次按五家官方资料整体复核，四家的记录都需要更正或补录：

- Kimi Code 列此前写“无独立桌面端；提供 VS Code/Web”，已过期。官方 CLI 参考在 `kimi install-desktop` 一节逐字写“打印 Kimi Code 桌面端页面地址并在默认浏览器中打开，无需离开终端即可下载并安装桌面端应用”，官方斜杠命令表列出 `/desktop`（别名 `/install-desktop`），中文更新日志把这两个入口记在 2.0.0（2026-09-17）与 2.0.1（2026-09-18）；2026-10-09 合入 main 的 PR #4145 又加了 `kimi app [path]`，用系统 URL scheme 在指定目录唤起桌面端新会话。
- Claude 与 Codex 的桌面端都已有 Linux 版，此前记录只写 macOS 与 Windows：Claude Desktop 官方页把 “Get Claude for Linux (beta)” 与 macOS、Windows 下载项并列，并有专页 `Claude Desktop on Linux (beta)`；ChatGPT 桌面应用官方页把安装步骤写成 “Download ChatGPT for macOS or Windows, or follow the Linux installation guide”，专页标注 “The ChatGPT desktop app for Linux is available in preview.”。
- Qwen Code Desktop 此前记为“Electron 应用通过 ACP 驱动随应用打包的 Qwen Code CLI runtime”，已过期：旧 Electron 桌面包在 2026-08-25 提交 `ce72ddbe6cfe`（PR #9085）移除，现在的 `packages/desktop` 是 2026-09-25 提交 `73aa65a4b41e`（PR #12653）从 `packages/desktop-shell` 改名而来的 Tauri 2 壳，README 第一句逐字为 “This package is an isolated Tauri 2 shell around the existing Web Shell. It does not contain a second UI.”。
- Qoder 列此前写“macOS 与 Windows 等官方支持桌面平台”，官方下载页把 Qoder IDE 的下载项列为 macOS 12+、Windows 10+ 与 Linux（`.deb`/`.rpm`）。

本次只处理 `surface-desktop` 一个能力字段；另外把 `surface-cli` 详情里与新结论直接冲突的一句（“当前没有独立 Kimi Code 桌面应用”）做了一致性修正，没有重新核对该字段的其他内容。

- Kimi 详情改写：入口改为 `kimi app [path]`、`kimi install-desktop`（隐藏别名 `kimi install-app`）与 TUI `/desktop`（别名 `/install-desktop`）；协议改为记录深链接 `kimi-code://open?root=<URL 编码路径>&new=1`、三平台 opener（macOS `open`、Windows `powershell.exe -NoProfile -NonInteractive -EncodedCommand` 内的 `Start-Process -FilePath ... -ErrorAction Stop`、Linux `xdg-open`）、opener 经 PATH 解析为绝对可执行文件并跳过落在当前工作目录内的命中（Windows 按 `PATHEXT`，缺省 `.COM`/`.EXE`/`.BAT`/`.CMD`；当前目录是文件系统根时不受限），以及下载页地址由 `kimiCodeOfficialInstallUrl()` 取 `${siteBase}/code`（国内 `https://www.kimi.com/code`、全球 `https://www.kimi.ai/code`）；行为改为记录“只唤起、不下载不安装”“目标工作区已存在时开新草稿而不恢复会话”“opener 报错时向 stderr 写安装提示并把退出码置 1”“`install-desktop` 先写 stdout 再打开浏览器且没有任何选项”“`/desktop` 显示 `<url> — opened in your browser`”；状态、工具、认证与运行位置改为按 CLI 侧可确认的范围记录，桌面端本体的会话共享、工具集、登录方式与平台清单标为未确认；条件补版本时间线（2.0.0 引入、2.0.1 改名、`kimi app` 于 2026-10-09 合入 main 且 changeset 记 minor、最新 Release 仍是 2.1.1 因此尚未发布）与“CLI 不检测桌面端版本、旧桌面端可能静默忽略该链接”。
