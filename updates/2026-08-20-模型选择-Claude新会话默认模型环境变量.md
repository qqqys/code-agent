# 模型选择：Claude Code `ANTHROPIC_DEFAULT_MODEL` 新会话默认模型（v2.1.236）

Claude Code v2.1.236（2026-08-19 发布，更新日志提交 `084ca20bcf90`）新增 `ANTHROPIC_DEFAULT_MODEL` 环境变量，用于指定新会话的默认启动模型。官方模型配置文档（code.claude.com/docs/en/model-config）与环境变量文档（code.claude.com/docs/en/env-vars）已同步记录该变量的优先级、忽略条件和恢复会话行为。矩阵 `model-switch`（模型选择与切换）字段的比较边界本就包含"会话级、项目级和用户级默认值"，本次在该字段内补录 Claude 新功能；同时按官方模型配置文档修正该字段 Claude 详情中已过时的 `/model` 持久化描述（"按 `d` 保存默认值"是 v2.1.144–v2.1.152 行为，自 v2.1.153 起 `/model` 选择默认写入用户设置）。Codex、Qwen Code、Kimi Code、Qoder CLI 四家的默认模型入口（`config.toml` `model`、`model.name` 与 `--project`/`--global`、`config.toml` `default_model`、`~/.qoder/settings.json`）与既有记录一致，本次未变化；Qoder 模型页（docs.qoder.com/cli/model，`en/cli/model` 现 308 重定向至此）复核仍只列 `/model` 与 `--model`，无模型环境变量。

## 修正

- `model-switch`（模型选择与切换）矩阵结论更新：Claude Code 列由 "`/model` · `--model`" 更新为 "`/model` · `--model` · `ANTHROPIC_DEFAULT_MODEL` 新会话默认模型（v2.1.236 起）"。Codex、Qwen Code、Kimi Code、Qoder CLI 矩阵结论不变。
- Claude Code 详情：入口新增 `ANTHROPIC_DEFAULT_MODEL`；支持范围补充该变量指定新会话默认启动模型、选择器 Default 行解析到该模型时显示标签 `Set by ANTHROPIC_DEFAULT_MODEL`；具体行为补充优先级规则——新会话只在 `--model`、`ANTHROPIC_MODEL`、任何设置文件的 `model`（含 `/model` 保存的选择）和组织默认模型均未指定时才采用该变量的模型，此时经 `--resume`、`--continue` 或 `/resume` 恢复的会话也改用该模型、不恢复记录中保存的模型；会话与作用域区分 `/model`（当前会话）、`--model` 与 `ANTHROPIC_MODEL`（本次进程）、`ANTHROPIC_DEFAULT_MODEL`（新会话启动模型）三层；持久化改为官方现行规则——自 v2.1.153 起 `/model` 选择器按 `Enter` 或直接输入 `/model <name>` 写入用户 Settings 的 `model` 字段作为新会话默认值、按 `s` 只切换当前会话、`-p` 非交互模式下 `/model` 不保存默认值，`ANTHROPIC_DEFAULT_MODEL` 不落盘且优先级低于 `/model` 保存的选择，设置 `ANTHROPIC_MODEL` 时每次启动都回到该变量的模型；安全与管理补充 `enforceAvailableModels` 开启、`availableModels` 或组织模型限制排除该模型、或账号不可用时变量被忽略；条件补充需 v2.1.236 及以上，取值为 `default`、`inherit`、`opusplan` 或 `haiku` 时被忽略。
- 跨产品事实第 3 条由"当前 `/model` 默认只改当前会话；在选择器按 `d` 才会保存用户默认值"改写为 v2.1.153 起默认保存与 v2.1.236 新变量优先级关系。
- `site/data.js`：新增来源 `claude-default-model-v236`（更新日志固定到提交 `084ca20bcf90`）；Claude 详情来源补充 `claude-env-vars` 与 `claude-default-model-v236`。
- `docs/09-版本与证据.md`：Claude Code 核对日期更新为 2026-08-20，主要材料新增 `ANTHROPIC_DEFAULT_MODEL` 新会话默认模型条目与 `/model` 自 v2.1.153 起默认保存新会话默认值条目；模型与认证来源表 Claude Code 模型与 Provider 列新增 v2.1.236 更新日志链接。
- `npm run generate` 重新生成 `docs/08-模型与认证矩阵.md` 与 `docs/capabilities/models/` 全部详情页，并把各详情页核对日期更新为 2026-08-20；`npm test` 通过。

- Claude Code 官方模型配置文档（code.claude.com/docs/en/model-config，2026-08-20 复核）"Set a default model for new sessions" 小节："Set `ANTHROPIC_DEFAULT_MODEL=<alias|name>` to choose the model your sessions start on by default.
