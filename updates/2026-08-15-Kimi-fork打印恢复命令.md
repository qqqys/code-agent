# Kimi Code `/fork` 打印恢复命令并复制到剪贴板

Kimi Code 官方仓库在 2026-08-15 合入提交 `6b72345f8bb0`（PR #2940），`/fork` 完成后除停留在原会话外，还会打印一条可直接运行的 `kimi --resume` 命令并复制到剪贴板，方便在新终端进程中直接进入派生会话。该提交晚于 0.36.1（2026-08-14 发布），changeset `.changeset/fork-print-resume-command.md` 级别 patch、尚未被 Release 消费，标注为"main 分支，尚未发布"。同一提交更新了中英文 Sessions 文档。同一发布（0.36.1）还包含回合运行中 fork 的报错修复，一并补入该字段条件。

## 修正

- `session-branch`（会话分支）矩阵 Kimi Code 列由 `/fork` 更新为"`/fork` · 条件：fork 后打印 `kimi --resume` 命令并复制到剪贴板（main 分支，尚未发布）"；详情的入口、具体行为、条件和来源同步补充命令格式（非 Windows `cd`、Windows `pushd`）、剪贴板三种结果提示、`--resume` 为 `--session` 隐藏别名，以及 0.36.1 起回合运行中 fork 报错。
- `cmd-fork`（分支会话）命令详情 Kimi Code 执行行为补充恢复命令打印与剪贴板复制（条件：main 分支，尚未发布），条件补充 0.36.1 起回合运行中 fork 报错；跨产品事实新增一条。
- Slash 命令矩阵 Kimi Code 命令目录说明补充 0.36.1 fork 报错与恢复命令打印两项行为及来源链接。
- 来源坐标：`kimi-sessions-current` 由提交 `7c919f0376c0` 改固定到 `6b72345f8bb0`（Sessions 文档在该提交更新）；新增 `kimi-fork-resume-command` 指向提交 `6b72345f8bb03487e3bcc05b541e65484818428c`，新增 `kimi-v0361-release` 指向 0.36.1 发布说明。
- Kimi Code 核对日期更新为 2026-08-15。

## 证据版本

- Kimi Code 官方仓库提交 `6b72345f8bb03487e3bcc05b541e65484818428c`（`feat(tui): print the fork resume command and copy it to the clipboard (#2940)`，2026-08-15T06:09:43Z）：`apps/kimi-code/src/tui/commands/session.ts` 新增 `forkResumeCommand()`，非 Windows 生成 `cd <workDir> && kimi --resume <forkId>`，Windows 用 `pushd` 代替 `cd`（cmd.exe 的 `cd` 不切换盘符，`cd /d` 会破坏 PowerShell）；fork 状态消息改为 "Session forked (<forkId>). Still in the original session; switch to the fork via /sessions." 附加 "To enter the fork in a new process, run: <command>" 与剪贴板结果（原生成功 "Command copied to clipboard"、OSC 52 回退 "Command copied via terminal escape sequence (unverified)"、失败 "Failed to copy command to clipboard"）。changeset `.changeset/fork-print-resume-command.md` 原文 “Print the full `kimi --resume` command after `/fork` and copy it to the clipboard, so the fork can be entered directly from a new CLI process.”，级别 patch。同提交 `docs/zh/guides/sessions.md` 新增 “fork 完成后，CLI 会打印一条可直接运行的 `kimi --resume` 命令（并自动复制到剪贴板），方便你在新终端进程中直接进入派生会话。”
- Kimi Code 提交 `6b72345f8bb03487e3bcc05b541e65484818428c` 处的 `docs/zh/reference/kimi-command.md`：`-r` / `--resume` 是 `--session` 的隐藏别名，在帮助信息中不显示；`--session [id]` 带 ID 时直接打开指定会话。
- Kimi Code 官方 Release `@moonshot-ai/kimi-code@0.36.1`（2026-08-14T12:53:36Z 发布）：Patch Changes 包含 “Show a clear error when forking a session while its turn is running, instead of copying a partially written turn.”（PR #2916）；不包含恢复命令打印（该提交 2026-08-15 合入，晚于发布）。
