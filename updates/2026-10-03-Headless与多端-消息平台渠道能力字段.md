# Headless、SDK 与多端：新增消息平台渠道能力字段，Qwen Code Email 渠道（IMAP + SMTP）合入 main

Qwen Code 官方仓库在 2026-10-03 合入提交 `612a55295993ffd60303cfc8d3445abac8ae2ad9`（PR #12939，`feat(channels): add IMAP and SMTP email channel`），给既有 Channels Surface 增加 `email` 适配器：用 IMAP 轮询收信、SMTP over TLS 回信，把邮箱当作 Agent 会话的输入与输出通道。核对该提交时发现矩阵此前完全没有字段区分“第三方消息平台/邮箱渠道”与厂商自有 Surface，而 Claude Code 也有一个此前未记录的一等 Channels Surface（官方文档 `code.claude.com/docs/en/channels` 与 `channels-reference`，研究预览内置 Telegram、Discord、iMessage 与 `fakechat` 演示渠道），因此本次新增 `surface-channels`（消息平台渠道）字段并覆盖五家产品。Codex 的 Slack `@ChatGPT` 提及委派给 Codex Cloud、Qoder 的 `@qoder` 提及由 GitHub Action 在 GitHub Runner 执行，两者都不属于 CLI 渠道；Kimi Code 在提交 `21406fb4c805` 时点没有任何第三方消息平台或邮箱适配器。五家核对日期同步更新为 2026-10-03。
