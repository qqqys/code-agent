# 跨会话消息：Codex `codex_tui` TUI 任务工具（main 分支，尚未发布）

Codex 跨会话消息字段在已发布的 `codex queue`（rust-v0.149.0）之外补录 main 分支新能力。2026-08-24 合入的提交 `a8468330bb5f`（PR #40308 “Add TUI tools for managing Codex tasks”）让 TUI 不再拒绝 app-server 动态工具调用（此前统一返回 “Dynamic tool calls are not available in TUI yet.”），而是注册 `codex_tui` 工具命名空间（描述 “Manage Codex tasks available through the connected app server.”），模型可在 TUI 会话内列出、读取、等待、发消息、创建、派生、重命名、归档其他 Codex 任务：九个动态工具为 `list_threads`、`list_archived_threads`、`read_thread`、`wait_threads`、`send_message_to_thread`、`create_thread`、`fork_thread`、`set_thread_title`、`set_thread_archived`。委派类工具 `create_thread`/`send_message_to_thread`/`fork_thread` 经 TUI 启动的审批门控本地 MCP 服务器（127.0.0.1 随机端口、Bearer UUID 令牌，以 `mcp_servers.codex_tui` 注入线程配置，三者 `approval_mode: "prompt"` 逐次批准）执行；MCP 传输只在连接本地 daemon 且非远程工作区或环境时启动，嵌入式 app server 不启用，外部 app server 不支持动态工具时回退为不带动态工具启动。合并提交晚于 rust-v0.149.1 标签（GitHub 比较显示该提交领先标签 139 个提交），官方发布说明、文档站与 Slash 命令表均未列出，按“合入 main 尚未发布”记录。
