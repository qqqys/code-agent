# Claude Code Self-hosted environments 自托管云会话执行

Claude Code v2.1.224（2026-08-07T04:00:59Z 发布，更新日志提交 `66edf5358349`）新增 Self-hosted environments：“Added self-hosted environments: `claude self-hosted-runner` turns your own machines or containers into a place Claude Code web, mobile, and desktop sessions can run, on Team and Enterprise plans”。官方现有四个文档页（概述、quickstart、部署、reference）描述该能力：组织在 claude.ai `Cloud environments` 管理页开启 `Allow self-hosted environments` 并创建环境后，自有 Linux/macOS 主机运行 `claude self-hosted-runner`，claude.ai、移动端、桌面端、终端 `claude --cloud` 与定时 routines 启动的云会话可以在环境选择器中选择该环境，由 Runner 认领、克隆仓库并派生 Claude Code 子进程执行。该版本发布在 Claude Code 2026-08-08 核对之后仍未被矩阵记录。本次把它并入现有 `surface-cloud`（云端仓库任务）字段，不新增能力字段。

## 证据版本

- Claude Code v2.1.224 更新日志（提交 `66edf5358349`，2026-08-07）： “Added self-hosted environments: `claude self-hosted-runner` turns your own machines or containers into a place Claude Code web, mobile, and desktop sessions can run, on Team and Enterprise plans”。v2.1.225 内容为 gateway spend-limit、`claude agents` 目录信任提示与 SendMessage 按名称发起跨机器对话（后者已记录），v2.1.226（提交 `2bb60696142b`，2026-08-08）仅 “Bug fixes and reliability improvements”。
- Claude Code 官方文档 Self-hosted environments（概述页）：“A self-hosted environment executes Claude Code cloud sessions on infrastructure your organization operates.”；“Self-hosting has three parts: Environment / Runner / Session”；“If they choose yours, Anthropic's control plane places the session on your environment's queue, where a runner claims it, clones the repository the developer chose, and starts a Claude Code process on your host to run it.”；“developers start them from claude.ai, the mobile and desktop apps, the terminal with `claude --cloud`, and scheduled routines”；“Claude Tag, Claude Security, and Code Review sessions don't route to them yet”；“public beta for Team and Enterprise organizations. Self-hosted environments are off by default; an Owner or admin turns on **Allow self-hosted environments** on the **Cloud environments** admin page, which requires Claude Code on the web to be enabled”；“unavailable for organizations with Zero Data Retention enabled”；“sessions use the Anthropic API, and inference can't be routed through Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, or an LLM gateway”；“sessions check out repositories from GitHub”；“the traffic to Anthropic, queue polling, the session's event stream, and model inference, is outbound HTTPS to `api.anthropic.com`”“Anthropic never connects into your network.”；与 Remote Control 的区分 “If you want to run Claude Code on your own always-on machine and drive it from other devices, use Remote Control, which is also available on Pro and Max plans.”。
- Claude Code quickstart 页：`claude self-hosted-runner --help`（v2.1.224+）、`claude self-hosted-runner setup` 引导、手动启动 `claude self-hosted-runner --environment-secret-file '/etc/claude/environment-secret' --base-dir '<writable-dir>'`；环境在 `https://claude.ai/admin-settings/cloud-environments` 的 Self-hosted environments 下创建；“claude.ai shows the secret once, and you can't retrieve it later; it expires 365 days after creation.”；会话从 claude.ai/code 环境选择器启动，“self-hosted environments appear alongside Anthropic-hosted ones”；CLI 跟进运行中会话用 `claude -p "your message" --cloud <session-id>`。
- Claude Code reference 页：`claude self-hosted-runner` 与 `orchestrator` 子命令；Runner 与 orchestrator “Both run on Linux or macOS hosts”；`--capacity` 默认 1 且 “All sessions belong to the same locked account”；`--environment-secret-file` 必填（环境变量 `SELF_HOSTED_RUNNER_ENVIRONMENT_SECRET` 直接携带密钥值）；`--base-dir` 默认 `/workspace`；`--health-port` 默认 8080 提供 `/healthz` 与 `/metrics`；`--trust-workspace` 默认开启；`--use-anthropic-git-proxy` 要求 `--capacity 1` 且 git 2.32+；`SELF_HOSTED_RUNNER_HOST_CONFIG_DIR` 默认 `~/.claude` 并注入每个会话的 `CLAUDE_CONFIG_DIR`；orchestrator 需 `--hooks-dir` 中的 `spawn-runner` hook，另有 `--hook-concurrency`、`--min-idle`、`--scm-connector-*`（GitHub Enterprise Server 连接器）等。
- Claude Code 部署页：“Anthropic doesn't publish a pre-built runner image. Build your own around the `claude` binary”（从 `downloads.claude.ai` 下载 linux-x64/arm64 二进制）；提供 Kubernetes 与 Docker Compose 部署示例；git 认证三种方式（Anthropic Git Proxy、`--configure-git`、镜像自带）；安全建议含 `--capacity 1` 一次性容器、默认拒绝出站、屏蔽 `169.254.169.254` 元数据端点、environment secret 不放在会话主机等。
- 其他四家本次不更新：Codex rust-v0.147.0（2026-08-07 发布）另有 `--approve-for-me` 自动审查批准、MCP 2026-07-28 协议支持、Cursor 托管 Skills 导入等变化，属于其他能力字段，留待后续单元核对；Kimi Code 0.34.0 后的提交（#2740、#2731、#2706、#2701、#2699、#2708、#2704、#2653）为内置 profile 隔离修复、SDK MCP 认证探测、搜索索引隔离、compaction 计数修复与文档同步，无托管云任务变化；Qwen Code 2026-08-09 合入（#8469、#8691、#8614、#8790、#8800 等）为 ACP/serve/web-shell/SDK/Desktop 修复与界面增强，Local Control 已在当日早些时候记录；Qoder CLI 公开文档无同类变化。
