# 增加模型与认证能力独立详情页

> 日期：2026-07-27

## 变化

- 将模型与认证从 6 个概括字段扩展为 12 个独立能力：模型选择、推理强度、Provider、自定义端点、浏览器登录、API Key、云厂商凭据、环境变量、凭据存储、退出、状态检查和组织策略。
- 为每个能力增加网页详情与 Markdown 详情，逐产品记录入口、机制、行为、作用域、持久化、自动化、安全、条件和一手来源。
- 修正 Qwen Code 当前认证入口：Qwen OAuth 免费层已停止，`/auth` 当前用于配置 ModelStudio、第三方或自定义 Provider。
- 明确 Kimi Code 只有 `KIMI_MODEL_*` 临时模型通道直接读取 Shell 环境，普通 Provider Key 不会按常见变量名自动发现。
- 明确 Codex 自定义 Provider 当前只支持 Responses wire API；Qoder CLI 公开 Custom Model 能力是指定厂商目录，不等同于任意兼容 URL。
- 修正 Claude Code `/model` 的保存语义和当前 effort 档位。

## 结果

整站 104 个能力字段均已有可打开的完整详情页，共 520 条逐产品记录。
