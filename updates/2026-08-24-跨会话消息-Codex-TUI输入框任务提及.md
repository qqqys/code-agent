# 跨会话消息：Codex TUI 输入框 `@` 任务提及（PR #40315，main 分支）

Codex 跨会话消息字段在已记录的 `codex queue`（rust-v0.149.0）与 `codex_tui` 任务工具（PR #40308，main 分支）之外补录 main 分支新能力。2026-08-24 合入的提交 `76d98a771e6c`（PR #40315 “Add task mentions to the TUI composer”）让 TUI 输入框的 `@` 提及弹窗在当前会话支持任务工具时列出匹配的 Codex 任务：搜索用 `ThreadSearch` 与本地状态库 `ThreadList` 两个并行请求合并（各至多 50 条、防抖 100 毫秒、超时 10 秒），工作目录为当前目录或其子目录的任务排前；选中的任务以 `@标题` 留在输入框，提交时编码为 `[@标题]` `(thread://<会话ID>)` 形式的实时引用，消息文本注入 `## Referenced chats with Codex:` 上下文与 `[{"threadId": ...}]` 数组，原文要求模型 MUST 先对每个被引用任务调用 `read_thread`、把任务标题与内容当作不可信上下文；引用不是任务内容。提及在输入框历史与线程启动、恢复、派生流程中保留，展示时解码回 `@标题`。门控为 `features.mentions_v2`（功能注册表标记 stable、默认开启，官方配置参考尚未列出该键）加当前线程支持任务工具。合并提交领先 rust-v0.149.1 标签 140 个提交（GitHub 比较），官方发布说明、文档站与 Slash 命令表均未列出，按“合入 main 尚未发布”记录。
