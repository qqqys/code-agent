# Kimi Code `/fork` 派生后停留原会话

Kimi Code 官方仓库在 2026-08-04 合入提交 `54c04bf03ddb`（PR #2565），`/fork` 不再切换到派生会话：fork 后停留在原会话，原会话保持活跃、后台任务继续运行，派生副本之后通过 `/sessions` 打开。该变更随 0.33.0（2026-08-05T08:24:45Z 发布）进入正式版本。矩阵的"分支会话"命令详情和"会话分支"能力详情此前按旧版本文档记录，未注明是否切换，本次补足；同一发布包含的 `/bug` 别名不再标注"尚未发布"。

## 修正

- `cmd-fork`（分支会话）详情 Kimi Code 执行行为更新为"基于当前会话派生保留完整对话历史的独立副本；fork 后停留在原会话，原会话后台任务继续运行，副本可随时通过 `/sessions` 打开"，条件补充"0.33.0 起不再切换到派生会话，此前版本 fork 后立即切换并关闭原会话"。
- `cmd-fork` 跨产品事实修正"Codex 与 Kimi Code 创建新会话"的旧表述，并新增 0.33.0 行为边界事实。
- `session-branch`（会话分支）详情 Kimi Code 的入口与切换、具体行为、条件补充"停留原会话、副本用 `/sessions` 打开"。
- Subagent 矩阵"Fork 会话"行 Kimi Code 列由 `/fork` 改为"`/fork` 创建副本；fork 后停留原会话"。
- Slash 命令矩阵"反馈或问题上报"行 Kimi Code 列移除"条件：main 分支，尚未发布"标注；Kimi Code 命令目录说明更新为"`/bug` 自 0.33.0（2026-08-05 发布）起包含"，并补充 `/fork` 行为说明。
- 来源坐标：Kimi Code Slash 命令文档由提交 `8db7d42f2347` 改固定到 `7c919f0376c0`（0.33.0 changelog 同步提交），会话文档由 `29783e471afc` 改固定到 `7c919f0376c0`；命令表仍为 43 个主命令，与矩阵目录一致，期间无其他命令增删。新增"`/fork` 不再切换会话提交"来源指向 `54c04bf03ddb`。

- Kimi Code 官方仓库提交 `54c04bf03ddbeb46d02b2edb460ea091ae194509`（`feat: /fork no longer switches to the forked session (#2565)`，2026-08-04T07:24:12Z）：changeset `.changeset/fork-stay-current-session.md` 原文 “`/fork` no longer switches to the forked session: the current session stays active and its background tasks keep running.
