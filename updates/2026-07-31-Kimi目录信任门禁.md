# Kimi Code 目录信任门禁（v2 引擎）

Kimi Code 在实验性 agent-core-v2 引擎中加入了启动目录信任提示，门禁项目级 MCP 配置。此前矩阵中 Kimi Code 的"项目目录信任"字段为"未确认"。

## 修正

- `security-trust` 矩阵 Kimi Code 列从"未确认独立目录信任门禁"更新为"条件：v2 引擎启动信任提示；项目 MCP 门禁"。
- 证据状态从"未确认"变为"条件项"。
- v2 引擎（`KIMI_CODE_EXPERIMENTAL_FLAG`）在 TUI 启动时显示 "Trust this folder?" 提示。
- 项目级 MCP（`.mcp.json`、`.kimi-code/mcp.json`）仅在受信任目录加载。
- 拒绝信任退出程序，下次启动再次询问；信任按目录持久保存。
- v1 引擎无信任概念，始终视为受信任。
- 来源固定到 commit `32d693f644de`（PR #2453）。
