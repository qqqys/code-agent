# Claude Code Subagent Fork 模式默认开启

Claude Code v2.1.232（2026-08-13 发布）把 Subagent Fork 模式改为默认开启：交互会话中 Claude 派生的 Subagent 可以是继承完整对话的 Fork，且非 Teammate 派生的 Agent 一律后台运行。官方 Subagent 文档以 “Fork the current conversation”、“How forks differ from named subagents”、“Turn fork mode on or off”、“Run subagents in foreground or background” 等章节完整描述该机制。矩阵 `agent-initial-context`（初始上下文）与 `agent-background`（后台与并行）字段此前只记录命名 Subagent 的任务描述启动与前台/后台支持，本次把 Fork 模式行为补入 Claude Code 记录。其余四家无同类变化：Codex Subagent 仍是父线程委派描述的独立线程，Qwen Code Fork 维持 `fork_turns` 继承规则（v0.21.12 发布说明未改变 Fork 上下文行为），Kimi Code 0.36.1 为 Web/TUI 修复，Qoder CLI 文档明确 Subagent 隔离上下文且后台为 `background` 显式开启，结论保持不变。

## 证据版本

- Claude Code 官方更新日志 v2.1.232（提交 `1f6015b5d578`，2026-08-13T23:29:53Z）原文："Subagent forking is now on by default: a `subagent_type: "fork"` subagent inherits the full conversation and prompt cache, and non-teammate agent spawns in interactive sessions now run in the background by default"。
- Claude Code 官方 Subagent 文档（https://code.claude.com/docs/en/sub-agents，2026-08-14 抓取）：Fork 定义 "A fork is a subagent that inherits the entire conversation so far instead of starting fresh. This drops the input isolation that subagents otherwise provide: a fork sees the same system prompt, tools, model, and message history as the main session..." 与 "Use a fork when a named subagent would need too much background to be useful, or when you want to try several approaches in parallel from the same starting point."；派生入口 "Claude starts a fork by requesting the `fork` subagent type through the Agent tool."；用户入口 "You can start a fork yourself with `/subtask` followed by a task, whether or not fork mode is on."、"Run a forked subagent with `/subtask`, which requires Claude Code v2.1.212 or later. When agent view is turned off, `/subtask` isn't available and `/fork` starts the forked subagent instead; otherwise `/fork` copies the whole session into a new background session."、"On v2.1.161 through v2.1.211 the command is `/fork`."；结果回传 "The fork's own tool calls still stay out of your conversation and only its final result comes back, so your main context window stays clean."；对比表 Fork 列 "Context: Full conversation history"、"System prompt and tools: Same as main session"、"Model: Same as main session"、"Permissions: Prompts surface in your terminal"、"Prompt cache: Shared with main session"（命名 Subagent 分别为 fresh context、definition file、`model` 字段、主会话提示、separate cache）；"Because a fork's system prompt and tool definitions are identical to the parent, its first request reuses the parent's prompt cache."；"Forks skip both filters and receive the main conversation's exact tool pool."（与既有 `agent-tools` 记录一致）；限制 "A fork can't spawn further forks."（与既有 `agent-nesting` 记录一致）、"An in-session fork you start with `/subtask` takes a slot while it runs and is never blocked by the limit."、Fork 可传 `isolation: "worktree"`（与既有 `agent-worktree` 记录一致）。
- Fork 模式开关（同一文档页 “Turn fork mode on or off” 章节）："Claude Code turns fork mode on by default in interactive sessions and leaves it off by default in non-interactive mode with `-p` and in the Agent SDK."、"`1` turns fork mode on in non-interactive mode and the Agent SDK as well"、"`0` turns fork mode off in every kind of session"、"The interactive default requires Claude Code v2.1.232 or later. On earlier versions, set `CLAUDE_CODE_FORK_SUBAGENT` to `1` to turn fork mode on."。
- 前台/后台选择规则（同一文档页 “Run subagents in foreground or background” 章节）："If you set `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS` to `1`, Claude Code runs the subagent in the foreground, in every kind of session and whether or not fork mode is on."、"If an in-process agent team teammate spawned the subagent, Claude Code runs it in the foreground."、"Where fork mode is on, as it is by default in an interactive session, Claude Code runs the subagent in the background, forks and named subagents alike, and Claude can't ask for the foreground."、"Where fork mode is off, Claude runs the subagent in the background by default and in the foreground when it needs the result before continuing... To keep a particular subagent in the background even when Claude wants the result, set its frontmatter `background` field to `true`."。
- 其他四家本次无同类变化：Codex 官方 Subagent 文档仍为父线程委派描述与独立线程（近期合入 #38592–#38606 为 Guardian 与 app server 内部变更，rust-v0.148.0 仅 alpha 通道）；Qwen Code v0.21.12（2026-08-14 发布）发布说明涉及 Web Shell 文件上传、autofix、daemon 与 review 条目，未改变 Fork 的 `fork_turns` 继承规则；Kimi Code 0.36.1（2026-08-14 发布）为 Web 界面与 TUI 修复，子 Agent 仍只接收任务描述；Qoder CLI 官方 Subagent 文档（2026-08-14 抓取）明确 "Each Subagent has its own conversation context, system prompt, tool registry, transcript, and compression flow."，后台为 `background` 字段显式开启，`initialPrompt` 仅在 `--agent` 会话 Agent 场景注入。
