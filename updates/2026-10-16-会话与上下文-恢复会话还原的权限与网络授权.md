# 恢复会话：Codex rust-v0.163.0 起冷恢复还原线程自有的审批策略、权限档与网络授权，五家「恢复时还原哪些会话内状态」逐项核对

Codex 官方 Release [rust-v0.163.0](https://github.com/openai/codex/releases/tag/rust-v0.163.0)（2026-10-15T21:30:38Z 发布，tag 提交 `83086188ae0614bd882818ff1aa23f3194962012`）的 Bug Fixes 第一条逐字为 “Resuming a saved thread restores its permissions and network approvals, while respecting explicit overrides and current managed policy.”，对应三个已合并到 main 的 PR：[#53150 “Restore thread-owned permissions on cold resume”](https://github.com/openai/codex/pull/53150)（合并提交 `7c9bfb910ef65c8f4a957c53affbd43d5fac2882`，作者时间 2026-10-11T15:30:11Z）、[#53419 “Restore saved thread permissions during configuration loading”](https://github.com/openai/codex/pull/53419)（`bf4ca52b61686398aafb6f4467da4202b6bdec53`，2026-10-12T16:01:44Z）与 [#53424 “Add regression coverage for network grants on cold thread resume”](https://github.com/openai/codex/pull/53424)（`fc4921f487a1f07275394a0476acb3d1edf1cd65`，2026-10-12T16:40:11Z）。三个合并时间都早于 0.163.0 的发布时间，因此这是已发布行为而不是 main 分支未发布状态。

这正是 2026-10-16 上一次研究单元在 `security-approval` 记录里显式留下的后续项——当时写明该条 “属会话恢复对权限状态的还原，本次未展开核对，留作后续研究单元”。本次把它展开，并顺带发现本仓库 `session-resume` 字段的 Codex 列此前只有 “`/resume` · `codex exec resume`” 一句，既没有 `codex resume` 这个 Stable 子命令、也没有 `--last`/`--all`/`--include-non-interactive` 三个参数与 `SESSION_ID` 接受会话名，更没有记录恢复会还原权限状态。旧记录的五家详情也都停留在「恢复对话历史」这一层，没有一家写清恢复时权限模式、会话内放行记录与网络授权各自是还原、丢弃还是需要重传。

本次把研究单元定为 `session-resume`（恢复会话）的「恢复时还原或丢弃哪些会话内状态」这一角度，五家全部重新取证。Codex 的结论只由 Release 与源码支撑——官方文档站（`learn.chatgpt.com/docs/agent-approvals-security`、`/docs/permissions`、`/docs/non-interactive-mode`、`/docs/developer-commands?surface=cli`）在核对日期都没有描述恢复会还原权限，这一点已写进来源标签。

本次只处理 `session-resume` 一个字段，能力字段总数维持 115，五行的核对日期都仍是 2026-10-16（同日上一次单元已改过），但五列的结论与证据都发生了实质变化。

本次取证分派给两个子代理并行完成，但两者的坐标都不能直接采信，全部经原始文件复核后才写入。除下节列出的两处否证外，还订正了本单元自己的一处中途错误结论：先前只 grep `packages/cli/src/config/config.ts` 就写下「Qwen v0.25.2 的 `--continue`/`--resume` 没有 `-c`/`-r` 短参别名」，实际上短参别名定义在 `packages/cli/src/config/top-level-options.ts` 第 382–393 行（`continue: { alias: 'c', … }`、`resume: { alias: 'r', … }`）。矩阵与详情页都已按订正后的事实书写，`docs/09-版本与证据.md` 的 Qwen 行也留了这条订正说明。
